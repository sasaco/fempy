モデルの入力

Wikiホーム · はじめに · 結果の読み方

ここでは、フレームの編集・連携で使うnode/member/element形式を説明します。省略のない最小モデルははじめににあります。Pythonが保存するnodes/elements/materials形式はファイル入出力で説明します。両者はフィールド名・階層が異なります。

単位と座標

計算時に単位を自動変換しません。力をF、長さをLとした場合の単位を、モデル全体で統一します。

量 単位 N・mを選んだ場合
座標、変位、板厚、部材荷重の位置 L m
力、反力 F N
モーメント F·L N·m
E、G、応力、面圧 F/L² N/m²
断面積A（梁） L² m²
Iy、Iz、J L⁴ m⁴
梁の分布力 F/L N/m
節点の並進ばね／回転ばね F/L、F·L/rad N/m、N·m/rad
梁の分布並進ばね／分布ねじりばね F/L²、F/rad N/m²、N/rad
回転変位 rad rad
部材のコードアングル 度 度
密度（時間をsとする） F·s²/L⁴ kg/m³

節点荷重・節点変位・反力は全体XYZ座標です。部材荷重は全体・局所のどちらかを指定します。梁の局所x軸はi端からj端へ向かい、Iyは局所y軸まわり、Izは局所z軸まわりの曲げに使われます。

ルートの項目

キー 内容・指定条件
node 節点辞書。必須。
member、shell、solid 構造要素。少なくともいずれかが必要。
element 材料ケース → 材料・断面ID → 特性。参照する材料を明示する。
dimension 梁モデルをXY平面に制限する場合は2。それ以外は3を用いる。
fix_node 支持ケース → 支持条件の配列。
fix_member 分布ばねケース → 部材ばねの配列。
joint 材端条件ケース → 回転解放の配列。
load 荷重ケース → 条件。複数ある場合、先頭を選択する。
notice_points 部材の着目位置・分割位置の配列。
rigid 部材端側の区間へ別材料を割り当てる配列。
analysis_type static、material_nonlinear、modal。
analysis_params 解析制御。選択した荷重ケース内の同名設定より優先する。
model_metadata 保存用JSONで使う座標系・一貫単位系の宣言。編集用旧JSONでは省略可。
boundary_conditions 強制変位・支持ばねを明示する補助形式。下記参照。

loadは静解析の荷重を与える通常の入口ですが、強制変位だけのモデルや固有値解析では省略できます。支持が不足したモデルは、荷重がゼロでも適切な解析モデルにはなりません。

節点・部材・材料

節点IDはJSONでは文字列のキーにします。参照するIDは整数または整数を表す文字列です。IDが連番である必要はありません。

{
"node": {
"10": {"x": 0.0, "y": 0.0, "z": 0.0},
"30": {"x": 2.0, "y": 0.0, "z": 0.0}
},
"member": {
"7": {"ni": 10, "nj": 30, "e": 1, "cg": 0.0, "shear_correction": false}
},
"element": {
"1": {
"1": {"n": "Steel", "E": 200000000000.0, "nu": 0.3, "G": 76923076923.07692,
"A": 0.01, "Iy": 0.00001, "Iz": 0.00001, "J": 0.00002,
"Xp": 0.000012, "den": 7850.0}
}
}
}

このブロックは入力項目の例で、支持・荷重を追加して使います。2Dでもx, y, zの3座標を指定します。部材の回転角は数値のcgです。cgにベクトルを渡す形式や、angle・code_angleという編集用JSONのキーは使いません。

材料キー 意味 要素ごとの扱い
E ヤング率 全要素で使用。正の有限値を指定する。
nu ポアソン比 通常の等方弾性では−1より大きく0.5未満。省略値は線形0.3、非線形0.2。
G せん断弾性係数 省略時はE/[2(1+nu)]。梁のせん断変形には別途下記の省略規則がある。
A 梁の断面積／シェルの厚さ 同じ名前でも単位が異なる。ソリッドでは不使用。
Iy, Iz, J 梁の曲げ・ねじりの断面値 梁で明示する。ソリッド・シェルには不要。
thickness シェルの厚さ 指定した場合はAより優先。正の有限値が必要。
Xp 線膨張係数 梁の温度変化に使用。
den 密度 固有値解析で明示する。
n 材料名 表示・識別用。
nonlinear JR履歴則 材料非線形解析を参照。

poiやcteという旧説明のキーは、現行のこの入力経路ではnu・Xpの代わりになりません。梁断面の省略値に頼らず、実際の断面を入力してください。

材料のGを省略すると、その材料を使う梁のせん断変形を無視します。 Gとshear_correctionの組合せによる詳細は要素の選び方を参照してください。

シェルとソリッド

{
"shell": {
"20": {"nodes": [1, 2, 3], "e": 2, "formulation": "dkt"}
},
"solid": {
"30": {"nodes": [1, 2, 3, 4], "e": 3, "type": "tetra"}
},
"element": {
"1": {
"2": {"E": 200000000000.0, "nu": 0.3, "A": 0.02},
"3": {"E": 200000000000.0, "nu": 0.3}
}
}
}

節点参照はnodes配列で指定します。シェルのni/nj/nk/nl形式や独立したルートthickness表を前提にしないでください。ソリッドはtypeを明示し、節点順序に従います。

編集用JSONはmember/shell/solidに別々のIDを持てますが、解析時に重複を解消してIDを振り直す場合があります。結果のキーは解析要素IDです。対応の確認方法は結果の読み方にあります。

支持条件と強制変位

通常の支持・支持ばね

fix_nodeのケース値は**配列**です。

{
"fix_node": {
"1": [
{"n": 1, "tx": 1, "ty": 1, "tz": 1, "rx": 1, "ry": 1, "rz": 1},
{"n": 2, "ty": 5000.0}
]
}
}

成分順はtx, ty, tz, rx, ry, rzで、全体座標の並進・回転です。

値 意味
0または省略 自由
1 変位・回転を0に拘束
0・1以外の有限数 その絶対値をばね剛性にする

このため、剛性1のばねをfix_nodeで表すことはできません。強制変位もこの実数欄では指定しません。次の明示形式を使います。

変位・ばねを明示する形式

{
"boundary_conditions": {
"restraints": {
"2": {"dof": [true, false, false, false, false, false],
"values": [0.001, 0, 0, 0, 0, 0]}
},
"spring_supports": {
"3": {"x": 1.0, "ry": 2000.0}
}
}
}

dofとvaluesの順序はdx, dy, dz, rx, ry, rzです。例では節点2のX変位を0.001に指定します。valuesの省略またはnullは0です。spring_supportsの方向名はx, y, z, rx, ry, rz、剛性は有限の正値です。ばねを設けない成分は省略します。

現行ソルバーには互換処理が残り、拘束された成分のvaluesの絶対値が1,000を超えると、強制変位ではなくばねとして解釈されます。Pythonの拘束APIにも共通する制約です。大きな数値になる単位系で強制変位を扱う場合は、モデル全体の単位を揃えて換算してください。

同じ節点をfix_nodeと明示的なrestraintsの両方に指定すると、**明示したrestraintsがその節点の拘束全体を置き換えます**。ばねは別に保持されます。併用時には意図しない支持を残していないか確認してください。

load_nodeのdx/dy/dzを強制変位として使う旧説明は、現行の読み込みに対応していません。

荷重ケース

{
"load": {
"service": {
"element": 1,
"fix_node": 1,
"fix_member": 1,
"joint": 1,
"load_node": [{"n": 2, "ty": -1000.0, "rz": 200.0}]
}
}
}
  • element, fix_node, fix_member, jointは各ケース表の参照です。省略時は1を参照します。対応する表を用意した場合、参照先のケースも必要です。
  • 節点荷重は全体座標です。力はtx, ty, tz、モーメントは**rx, ry, rz**です。HTTP入力の節点モーメントをmx, my, mzにはしません。
  • rate・symbolはこの解析経路で荷重倍率を適用するキーではありません。線形の倍率を変えるときは荷重値を変更します。非線形載荷の倍率にはload_factorsを使います。
  • loadに複数ケースを入れた場合、先頭のケースだけを解析します。返値も1ケース分です。全ケースを個別実行する例を参照してください。

解析制御

ルートのanalysis_params、または選択した荷重ケース内に指定できます。同じキーがある場合はルート側が優先です。ルートのanalysis_typeが未指定なら、荷重ケース内のanalysis_typeも使われます。

キー 既定値 対象・意味
n_load_steps 10 非線形の等間隔載荷段階数。正の整数。
max_iterations 50 各非線形段階の最大反復回数。正の整数。
tolerance 1e-6 非線形の相対残差・変位増分の判定値。正の有限値。
load_factors 未指定 非線形の載荷係数列。指定すると等間隔列に優先。
n_modes 10 固有値解析で要求するモード数。

例："analysis_params": {"load_factors": [0, 0.5, 1, 0.5, 0, -0.5, -1]}。有限数からなる空でない一次元配列を使います。各係数は増分ではなく、基準荷重・基準強制変位に対するその段階の倍率です。

部材途中の荷重

load_memberは荷重ケース内の配列です。位置は部材の長さと同じ単位で指定します。

mark 種類 指定方法
0 無効行 残った荷重値・位置も計算と分割に使用しない
1 集中力 L1,P1とL2,P2で最大2点。どちらのLもi端からの距離
11 集中モーメント 集中力と同じ位置指定。directionはモーメント軸
2 線形変化する分布荷重 P1,P2は載荷区間の始点・終点の強度
9 梁の一様温度変化 P1が温度変化。材料のXpと組み合わせる
{
"load_member": [
{"m": 1, "mark": 2, "direction": "gy", "L1": 0.5, "L2": 0.0, "P1": -1000, "P2": -2000},
{"m": 1, "mark": 1, "direction": "gy", "L1": 1.0, "P1": -500, "L2": 0, "P2": 0},
{"m": 1, "mark": 9, "P1": 20}
]
}

directionは局所方向がx, y, z、全体方向がgx, gy, gzです。分布ねじりモーメントには局所rを使えます。方向を省略すると局所yですが、誤解を避けるため明示してください。

分布荷重のL2は、通常は「j端から載荷終了位置までの距離」です。 部材長をLとすると、載荷範囲は[L1, L−L2]です。L2 < 0の場合は載荷幅として扱い、範囲は[L1, L1−L2]になります。L1=0, L2=0は全長載荷です。集中荷重のL2とは意味が異なります。

温度荷重はload_memberのmark: 9で指定します。load_heatを別の荷重表として与えても、この読み込み経路では処理されません。

着目点・剛域・分布ばね・材端解放

以下はいずれもルートに追加する項目です。

{
"notice_points": [{"m": 1, "Points": [0.5, 1.0]}],
"rigid": [{"m": 1, "Ilength": 0.2, "Jlength": 0.3, "e": 2}],
"fix_member": {"1": [{"m": 1, "tx": 0, "ty": 1000, "tz": 0, "tr": 0}]},
"joint": {"1": [{"m": 1, "zi": 0, "zj": 1}]}
}
  • **着目点**：i端からの距離で指定します。部材内の位置で分割し、新しい節点・要素を作ります。分布荷重の境界や集中荷重の位置でも分割します。
  • **剛域**：i端からIlength、j端からJlengthの区間を、eで指定した別材料・断面にします。完全剛体拘束ではなく、その特性値による区間です。例では材料・断面2を別途定義します。
  • **部材分布ばね**：tx, ty, tzは局所方向の単位長さ当たりの並進ばね、trは局所x軸まわりの分布ねじりばねです。旧形式では指定値の絶対値を使います。
  • **材端条件**：xi, yi, zi, xj, yj, zjは局所x/y/z軸まわりの**回転**について、0=解放、1=接続です。省略した軸は接続です。並進力の解放を表す欄ではありません。分割後も元部材の外側の端に適用します。

すべての梁断面値A, Iy, Iz, Jが0の線形部材は、部材途中の荷重を元の両端へ伝達するために使えます。構造剛性を与えず、剛域・分布ばねと組み合わせられません。荷重伝達部材の例を参照してください。

面圧

シェル全体への一様面圧は、Pythonのmodel.boundary.add_pressure(...)、または**保存用JSON形式**のboundary_conditions.pressuresで指定します。

{
"boundary_conditions": {
"pressures": [{"element_id": 20, "face": "F1", "pressure": 1000.0}]
}
}

F1は節点順序から定まる法線側の面です。正の面圧はその面から内向き、すなわち法線と逆方向に作用します。F2は反対側で、同じ正圧なら作用方向が逆になります。F1/F2は辺番号ではありません。

現行の編集用node形式に上記のpressuresを追加しても読み込まれません。シェル面圧の完全な実行例のnodes/elements形式を使ってください。ソリッド面の面圧入力は、このシェル用機能の対応範囲には含めません。

入力の確認ポイント

座標と荷重が有限値であること、参照先が存在すること、要素長・板厚・材料値が適切であることを確認します。JSONの未知のキーや誤った階層の一部は拒否されず無視されるため、HTTP 200だけで意図した条件が適用されたとは判断できません。小さなモデルで変位と釣合いを確認してから拡張してください。
