# PQ-09 メッシュ誤差・適用範囲の検証報告

実施日: 2026-09-10  
基準HEAD: `c5e30358eb420d13436d0e1d5137e544d3d59bfb`  
対象: 線形梁、DKT三角形シェル、MITC4四角形シェル、8節点六面体ソリッド  
実行器: [`tools/validation/mesh_convergence.py`](../../tools/validation/mesh_convergence.py)  
回帰試験: [`tests/validation/test_mesh_convergence.py`](../../tests/validation/test_mesh_convergence.py)

## 結論

滑らかな非一様変形に対し、梁は変位4次・曲げモーメント2次、DKTとMITC4は変位約2次・
曲げモーメント約1次、Hexa8は変位2次・応力1次で収束した。ひずみエネルギーの相対誤差も
全系列で単調に減少した。

今回の板ストリップではMITC4の板厚を`0.2`から`0.002`へ変えても変位・曲げモーメント誤差は
増えず、せん断ロッキングは観測されなかった。一方、Hexa8の等容な製造解では
`nu=0.49`から応力・エネルギー誤差が急増し、`nu=0.499`で応力L2相対誤差18.03、
エネルギー相対誤差0.388となった。現行の完全積分Hexa8を非圧縮極限へ一般利用できるとは
評価しない。

この結果は下記の滑らかな3問題と測定範囲に限る。点荷重、再入隅、き裂先端などの
応力特異性は含まないため、特異点を含むモデルの点応力や同じ収束率を保証しない。

## 独立参照解

期待値は製品ソルバーから生成していない。実行器に次の式、積分則、荷重組立を保存した。

### 梁

長さ`L=2`、`E=1000`、`Iz=4`のEuler–Bernoulli片持ち梁へ一様線荷重`q=3`を載荷した。
境界値問題`EI w''''=q`の閉形式解を使う。

```text
w(x) = q x^2 (6 L^2 - 4 L x + x^2) / (24 EI)
M(x) = q (L - x)^2 / 2
U    = q^2 L^5 / (40 EI)
```

製品の分布荷重経路で2、4、8要素を解き、節点変位・回転から独立に構成した三次Hermite場を
8点Gauss積分した。

### 板

長さ2、幅1、`E=1000`、`nu=0`の片持ち板ストリップへ一様面圧`q=1e-4`を載荷した。
DKTはKirchhoff板、MITC4は同じ実装の`5/6`横せん断係数を含むReissner–Mindlin板の
閉形式解と比較した。`D=Et^3/12`、`S=(5/6)Gt`とする。

```text
w_b(x) = q x^2 (6 L^2 - 4 L x + x^2) / (24 D)
w_s(x) = q (L x - x^2/2) / S                 # MITC4のみ
M_x(x) = q (L - x)^2 / 2
U      = q^2 L^5/(40D) + q^2 L^3/(6S)        # DKTでは第2項なし
```

三角形はDuffy変換6×6点、四角形は6×6点の独立積分で誤差を測った。各要素の局所曲げ
モーメントテンソルは全体座標へ回転してから参照解と比較した。

### ソリッド

単位正方形断面、奥行0.25、`E=1000`の領域で、次の等容な製造解を用いた。

```text
u = (a x^2, -2 a x y, 0),  a = 0.01
b = (-2 mu a, 0, 0),       mu = E/[2(1+nu)]
```

`div(u)=0`であり、`-div(sigma)=b`を満たす。x–y外周だけに厳密変位を課し、内部自由度は
製品ソルバーで解いた。一定体積力の整合節点荷重は、製品要素を呼ばずに標準Hexa8形状関数を
4×4×4点積分して組み立てた。Q1補間は`x^2`を要素内で再現できないため、通常の補間誤差と
非圧縮極限での体積ロッキングを同じ厳密解に対して測定できる。

## ノルムと収束率

- 変位誤差: 梁はHermite変位、板は節点横変位の線形補間、ソリッドは変位ベクトルの相対L2ノルム。
- 応力誤差: 梁は曲げモーメント、板は全体座標の曲げモーメントテンソル、ソリッドは
  `[xx, yy, zz, xy, yz, zx]`応力ベクトルの相対L2ノルム。
- エネルギー誤差: 数値ひずみエネルギーと閉形式ひずみエネルギーの相対差。
- 実測次数: メッシュ幅を1/2にしたときの`log(e_h/e_h/2)/log(2)`。

板の「変位L2」は節点結果の線形可視化場を評価する指標で、DKT内部の高次回転補間そのものの
L2評価ではない。応力成分のL2は成分を同じ単位で比較するEuclidノルムであり、材料柔性で
重み付けしたエネルギーノルムではない。

## 保証しない範囲

- この3問題だけから、任意形状・任意荷重・すべての要素型の精度を保証しない。
- 点荷重、角部、材料界面、再入隅の点応力はメッシュ細分化でも有限値へ収束しない場合がある。
- DKTの横せん断変形、曲面シェル、幾何学的非線形、大変形は対象外である。
- MITC4の結果は一方向の滑らかなストリップ解であり、一般の歪んだ薄板でロッキングがないとは
  結論しない。
- Hexa8の`nu=0.49`以上は、混合定式化や選択低減積分を持たない現行実装の検証済み適用域に
  含めない。
- Tetra、Wedge、二次ソリッド、三角形Mindlinのメッシュ収束率は今回測定していない。
