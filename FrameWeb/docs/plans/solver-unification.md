# 線形・材料非線形ソルバーの統合計画

作成日: 2026-09-09

状態: 実装・検証完了（2026-09-09）。[実施記録](../report/solver-unification.md)。材料非線形857成功、全件1,200成功・既知308失敗で変更前基準に一致。

調査基準: HEAD `a3a1fd1` と作成時の作業ツリー。曲率出力などの未コミット変更を含むため、実装開始時に差分を再確認する。

## 目的

`NonlinearSolver(Solver)` という継承関係を、共通の解析フローと釣合い解法の選択へ置き換える。
線形解析は「一定剛性・履歴非依存の問題を、通常は全荷重の1ステップで解く」特殊ケースとして扱う。
DOF管理、組み立て、境界条件、結果整形を共通化し、線形と非線形の双方へ同じ修正を書く必要をなくす。

荷重ステップ数だけで線形・非線形を判定しない。非線形問題は1ステップでも反復が必要であり、
線形問題に複数の荷重係数を与えても材料則は線形のままである。

共通の釣合い式は `f_int(u) = λF` とする。線形では `f_int(u) = Ku` かつ `K` が一定なので、
`KΔu = λF - Ku` は原理上1回の変位更新で釣り合う。支持ばねと強制変位は共通の境界処理で扱う。
ここで「1回」は構造的な釣合い更新を指し、既存の数値精度補償に必要な補正計算まで禁止するものではない。

## 現状の問題と維持する差異

| 対象 | 現状 | 統合方針 |
|---|---|---|
| 節点変位 | 親子で整形が重複。3DOFでは親だけ回転3成分をゼロで返す | 内部整形を一本化し、既存出力の差は互換境界で明示する |
| 反力 | 支持点選択、補助拘束の除外、ばね支持、成分名変換が重複 | 力ベクトルの計算と辞書化を分離し、辞書化を一本化する |
| 組み立て | 剛性・質量・接線剛性でDOF列挙と加算が重複 | 要素DOFと加算を共通化し、要素の評価方法と精度補償方式を分ける |
| DOF数 | 共通ヘルパーがあるのに親の各組み立てで型判定を再実装 | メッシュから一度決定し、同じ対応表を全処理へ渡す |
| 境界条件 | 適用自体は共通化済み。支持ばね残差はNewton・探索候補・境界適用に分散 | 支持ばね力の評価と拘束DOFへの射影を共有し、二重減算を防ぐ |
| 数値解法 | 親は対角スケーリングと精度補償、子は行最大値スケーリングと別の残差基準 | 呼出し契約を揃え、数値方針は明示して保持する |
| 解析API | `NonlinearSolver.solve()` は親の線形解析のまま | 解析選択を共通入口で明示し、旧APIは委譲に限定する |

線形側の `assembled_stiffness_correction`、`displacement_correction`、補償積・反復改良、
梁の釣合い補正は削除しない。非線形側の収束条件、バックトラック、特異性検出、
要素履歴の確定・復元も保持する。数値アルゴリズムの全面変更はこの計画に含めない。

## 到達する構成

`Solver` を静解析の共通入口とし、準備、荷重ステップ、釣合い求解、結果保存を所有させる。
巨大な1ファイルにまとめる必要はない。補助モジュールは責務のまとまりに応じて抽出するが、
線形／非線形それぞれにDOF・荷重・出力処理一式を持たせない。

| 責務 | 所有先・動作 |
|---|---|
| 解析選択と入力の正規化 | `FemModel` が既存の解析種別と既定値を解決し、共通ソルバーへ渡す |
| 解析準備 | メッシュのDOF対応、要素DOF、荷重、拘束・ばね、解析ごとの状態を準備 |
| 荷重ステップ | 共通フロー。通常の `static` は `[1.0]`、非線形は既存の係数列を使用 |
| 要素応答 | 線形は参照弾性剛性による応答、非線形は要素の内力・接線剛性APIを使用 |
| 釣合い求解 | 線形の直接解法とNewton反復を、小さな関数または内部オブジェクトとして選択 |
| 数値線形代数 | 状態を変更しない計算処理として解と必要な補正成分を返す。旧メソッドの状態更新はラッパーで維持 |
| 結果保存 | 受理した変位・内力・端力・曲率等をスナップショット化し、最終結果にも利用 |
| 後処理 | 既存の `FemModel` による端力回復・シェル出力等を維持し、共通DOF情報を利用 |

線形要素へ新しい抽象メソッドを一斉に強制する変更は避け、共通の応答評価層で既存APIを扱う。
要素内部の材料則と接線剛性の定式化は変更しない。

共通フローは次の順序を基本とする。

1. 解析条件を検証し、解析単位の状態とDOF対応を初期化する。
2. 指定された材料評価方法に対応する釣合い解法を選ぶ。
3. 荷重係数ごとに外力・要素荷重係数・強制変位の目標を設定する。
4. 最後の確定状態を保持して、直接解法またはNewton反復で釣合いを求める。
5. 成功した状態を確定し、履歴を進めない読み取りで結果を保存する。
6. 保存後にコールバックを呼ぶ。釣合い失敗時は確定状態へ戻し、後続ステップへ進めない。

線形の経路ではNewton用の残差・変位増分による追加収束反復を行わない。
直接解法の特異性検査と釣合い精度検査は維持する。履歴を持たない要素のcommit／rollbackは不要とする。

## APIと出力の移行方針

- `Solver.solve(mesh, material, boundary, elements)` の既存位置引数と線形動作を維持し、解析種別・反復条件は追加のキーワード引数で受ける設計とする。
- `FemModel.run()` の `static`、`material_nonlinear`、`modal` と既定の自動選択を維持する。荷重ステップ数から解析種別を推測しない。
- `nonlinear_bar` を含む入力でも、明示的な `static` は現行どおり参照弾性剛性と対応する線形端力を使う。要素に非線形APIがあるという理由だけで材料評価を切り替えない。
- `FemModel` 内部の解析と後処理を共通ソルバーへ移し、`NonlinearSolver` と `solve_nonlinear()` は移行中の薄い互換ラッパーとする。旧import、既定値、例外型・属性、公開状態の参照を維持する。
- 互換ラッパーは反復・組み立て・整形を独自実装しない。`FemModel.nonlinear_solver` の利用箇所も調査し、必要なら共通状態への互換アクセスを残す。
- 内部の節点変位は6キーを持つ正規形とし、3DOFの回転はゼロとする。移行中は旧非線形APIの3キー出力を境界で射影して維持する。HTTPを含む外部出力のキー追加は本変更で黙って行わない。
- 線形出力へ `step_results` や非線形の履歴情報を無条件に追加しない。内部の共通結果から各既存APIの出力形式へ変換する。
- 非線形の `step_results`、`convergence_history`、反力、端力、`curvature`、最終結果と各ステップの独立した配列・辞書を保持する。
- 線形の `displacement_correction` と、それを使用する後処理を保持する。非線形反力を一律に `K_tangent @ u - F` で計算しない。
- `modal` は固有値問題であり、静的釣合いの1ステップ扱いにしない。共通のDOF・剛性・質量組み立てを利用し、既存の固有値解析APIと境界処理を維持する。

互換ラッパーの削除は本計画の完了条件にしない。まず製品内部から旧実装への依存をなくし、
旧呼出しが同じ処理へ委譲される状態を完成させる。

### 第1段階: 現行契約と基準結果の固定

- [x] 実装開始時のHEAD・作業ツリー差分を記録する。並行作業の曲率出力・期待値監査等を上書きしない。
- [x] `Solver`、`NonlinearSolver`、`FemModel`、HTTP、後処理、例外import、ソルバー属性への参照を調査する。
- [x] 現行テストと独立参照から、下記検証表の基準を記録する。過去レポートの成功件数を現在の実行結果として扱わない。
- [x] 既存テストにない出力互換・再解析・失敗時状態の契約だけを追加する。新しい統合入口の振る舞いは実装前に失敗を確認する。

### 第2段階: 共通のDOF・組み立て・整形を抽出

- [x] DOF数の判定、飛び番節点の対応、要素DOF列挙を一元化する。荷重組み立ての副作用に依存して対応表が初期化される構造を解消する。
- [x] 剛性・質量・接線剛性・内力・要素変位抽出に共通のDOF情報を使う。精度補償付きの加算経路も同じ対応表を使う。
- [x] 反力ベクトルから支持点出力への変換と、節点変位の内部整形を一本化する。
- [x] 支持ばね力と自由DOF残差の評価を共通化する。Newtonの収束判定と探索候補で同じ釣合いを評価する。
- [x] 線形／非線形の入口はこの段階では維持し、抽出前後で同じ外部結果になることを確認する。

### 第3段階: 釣合い解法と状態管理を分離

- [x] 線形の直接解法と精度補償、Newton反復をそれぞれ釣合い求解処理として抽出する。
- [x] Newton内部の線形方程式解法は変位増分を返し、確定変位を上書きしない契約にする。
- [x] スケーリング、数値ランク、残差基準、補正成分の差を明示する。異なる数値方針を無理に単一の閾値へ統一しない。
- [x] 非線形要素の試行評価・確定・復元の順序を維持する。端力・曲率の読み取りで履歴が進まないことを確認する。
- [x] 線形の空の無荷重回転DOF除去を保持し、剛体モード・不安定系を成功扱いしない。非線形へ同じ除去を拡張するかは要素契約と再現テストで判断し、抽出時に暗黙変更しない。

### 第4段階: 共通の解析フローへ接続

- [x] 共通入口で解析条件を正規化し、線形は通常1ステップ、非線形は既存係数列で実行する。
- [x] 共通フローから材料評価方法と釣合い解法を選択する。線形要素を非線形経路で解く既存検証も可能にする。
- [x] ステップ結果保存と最終結果作成を共通化し、最後の状態を不要に再評価しない。
- [x] 失敗時の変位・要素履歴・荷重係数等の状態を整理し、再解析に残留しないことを検証する。公開APIの例外・コールバックの挙動を維持する。
- [x] `FemModel` の実行・後処理を共通ソルバーへ接続し、旧非線形クラスを委譲だけの互換ラッパーへ縮小する。

## 検証表

| 保証する挙動 | 検証方法・主な配置 |
|---|---|
| 線形の1ステップ解法 | 軸力梁等の手計算による変位・反力。Newton反復を経由しない契約も確認。`tests/solvers` |
| 線形とNewtonの整合 | 同一の線形要素モデルを両経路で解き、独立参照に対して各々確認。両実装同士の一致だけを正解としない |
| DOFと境界 | 3／6DOF、混在、飛び番・入力順、強制変位、旧形式と明示形式のばね、補助拘束。`tests/solvers`、`tests/integration` |
| 荷重と反力 | 節点荷重・分布荷重・面圧、固定DOFの巨大荷重、荷重係数、ばね力の一度だけの反映。`tests/integration` |
| 線形精度 | 大きく異なる剛性尺度、梁の小さな反力、変位補正、1次・2次ソリッドの精度補償。既存の独立参照と閾値を維持 |
| 特異性 | 無荷重でも不安定系は失敗。線形の解放回転DOFの扱いも維持。`tests/solvers`、梁の既存統合試験 |
| 材料履歴 | 単調載荷、反転・繰返し、非線形1ステップ、未収束時の最終確定状態への復元。`tests/materials`、`tests/integration` |
| 出力の整合 | 変位・反力・端力・応答曲率、ステップと最終結果、コピーの独立性、後処理で履歴が進まないこと |
| API互換と再利用 | 旧importと呼出し、明示staticの参照弾性応答、HTTP・保存読込、解析種別切替、失敗後の再解析。`tests/io`、`tests/integration` |
| 固有値解析 | 共通組み立て・DOF整形の変更による回帰を確認。解析方式自体は変更しない |
| 保存サンプル | beam001の全保存段階と独立参照、一般FEMの既知失敗基準を変更前後で照合。`tests/regression`、`tests/validation` |

実行入口は実装時点の [tests/README.md](../../tests/README.md) に従う。
各段階では変更した責務の関連テストを実行し、統合後は材料非線形の検証範囲と全件の既知失敗照合を実行する。
出力形式を意図的に正規化する場合も、数値の許容誤差は既存の各参照基準を保持する。
保存期待値の自動更新、許容誤差の緩和、skipの追加によって統合を成功扱いにしない。
全件の既知失敗照合成功と全テスト成功は区別して報告する。

## 対象外と完了条件

幾何学的非線形、新しい材料則、自動荷重刻み、弧長法、動解析、新しい線形複数ステップ公開API、
固有値解析アルゴリズムの修正は対象外とする。一般FEMの既知不具合修復は
[別計画](general-fem-followup.md)で管理し、今回の抽出で生じた回帰は本計画で修正する。

完了条件は、静解析の共通入口・準備・ステップ結果保存が一つになり、線形と非線形が必要な
釣合い解法と要素評価だけを選択すること、旧APIが共通実装へ委譲されること、
既存の精度・履歴・出力契約が保たれ、変更前基準に対する新規回帰がないこととする。
単なるファイル結合や、線形を現行Newtonループへ通すだけの変更では完了としない。
