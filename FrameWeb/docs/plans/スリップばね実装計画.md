## 1. 追加したい機能の理解

`fix_node`で設定する節点と固定地盤の間の支持ばねに、7.19の履歴特性を追加する。全体座標系の各並進・回転自由度へ個別に設定する。

初期は勾配K1で力が増え、変形が±δ1を超えると勾配K2に移る。そこから戻すとK1で除荷し、力がゼロになった後は抵抗しない区間を進む。再び載荷すると、そのゼロ力区間を抜けてK1の直線をたどり、過去の最大変形を超えたところでK2の骨格へ復帰する。

したがって、同じ変位でも過去に到達した変位によって支持反力が変わる。現在の変位だけで線形ばねの係数を切り替える実装では足りず、正負の履歴を保持する必要がある。

梁のJR材料則や`fix_member`の部材分布ばねを変更する機能ではない。梁がすべて線形でも、支持ばねだけがスリップするモデルを解析できるようにする。

## 2. 理論を実装可能な形に整理する

### 2.1 変形・力・骨格

並進ではδは節点の変位、Fはばねの内力、回転ではδは節点回転角、Fは対応するモーメントとする。支持側の変位はゼロとする。曲げ材料則のδである「曲率」と混同しない。

初回の実装は正負対称とし、入力は`K1, K2, delta_1`の3値、`P1 = K1 * delta_1`を導出する。

\[
F_b(\delta)=
\begin{cases}
K_1\delta & |\delta|\leq\delta_1,\\
\operatorname{sgn}(\delta)\{K_1\delta_1+K_2(|\delta|-\delta_1)\}
 & |\delta|>\delta_1.
\end{cases}
\]

`K1 > 0`、`delta_1 > 0`、`0 <= K2 <= K1`かつ有限値を受け入れる。`K2 = 0`は降伏後一定力、`K2 = K1`は線形ばねへ退化する。この範囲は原文の明示的な入力制約ではなく、図のスリップ区間を矛盾なく実装するために採用した仕様である。負のK2、K2 > K1、正負非対称は初回の対応範囲外として明示的に拒否する。

### 2.2 原文のゼロ力位置の式は修正が必要

原文4には`δmax± (1 ± Fmax± / K1)`とあるが、`F/K1`は変形の次元を持ち、1との加減算は次元が合わない。実装へそのまま転記しない。

反転点からの除荷直線は、力・変形をともに符号付きで表せば、

\[
F=F_{\max}^{\pm}+K_1(\delta-\delta_{\max}^{\pm})
\]

である。したがってゼロ力位置は、

\[
\delta_0^+=\delta_{\max}^+-\frac{F_{\max}^+}{K_1},\qquad
\delta_0^-=\delta_{\max}^--\frac{F_{\max}^-}{K_1}.
\]

ここでは`δmax- <= 0`、`Fmax- <= 0`とする。負側の力を正の大きさ`Qmax-`で持つなら、後式は`δ0- = δmax- + Qmax-/K1`となる。この導出と図を根拠に、実装段階で7.19の式・符号の説明も修正する。

### 2.3 履歴範囲内の応答

正負の最大経験点とゼロ力位置が確定しているとき、最大経験点の間では次の応答となる。

| 変形範囲 | F | 接線Kt |
|---|---|---|
| `δmax- < δ < δ0-` | `K1 * (δ - δ0-)` | K1 |
| `δ0- < δ < δ0+` | 0 | 0 |
| `δ0+ < δ < δmax+` | `K1 * (δ - δ0+)` | K1 |
| 過去の最大変形を正・負側へ超える | その側の骨格`Fb(δ)` | K2 |

未降伏側は、計算上の境界を`(δ1, P1)`または`(-δ1, -P1)`に置き、ゼロ力位置を0にする。これは「経験した最大点」の記録とは別に扱う。例えば正側のみ降伏した後も、負側の最初の載荷は原点からK1で進む。

実装で補う端点・反転の規則は次のとおり。

- 初期弾性内の反転では同じ原点を通るK1の直線を戻る。
- K1の除荷・再載荷直線上で再反転しても同じ直線を戻り、最大経験点を縮めない。ゼロ力区間内の反転でも境界を動かさない。
- 新しい最大変形では骨格上の点を候補履歴へ記録する。確定は全体釣合いが収束したときに限る。
- 折れ点・最大点・ゼロ力位置のFは連続とし、接線は進行方向側の片側勾配を使う。変位増分ゼロでは確定状態を保持し、最初の予測用接線と、増分方向が定まった後の接線の選択を試験する。
- 一つの試行評価は前の確定変形から試行変形までの単調経路として扱う。途中の反転は荷重・変位の履歴点として入力する。複数境界を飛び越える試行でも、終点の力と候補履歴を正しく返す。

### 2.4 手計算による基準値

`K1 = 1000 kN/m`、`K2 = 100 kN/m`、`delta_1 = 0.010 m`とする。次の順序で変位を確定させる。

| 順序 | δ [m] | F [kN] | 確認する挙動 |
|---|---:|---:|---|
| 1 | 0.005 | 5 | 初期弾性 |
| 2 | 0.030 | 12 | 正側降伏、ゼロ力位置は0.018 |
| 3 | 0.024 | 6 | K1で除荷 |
| 4 | 0.018 | 0 | ゼロ力位置 |
| 5 | 0.010 | 0 | スリップ区間 |
| 6 | 0.025 | 7 | 正側再載荷、最大点は0.030のまま |
| 7 | 0.000 | 0 | 再除荷して原点へ |
| 8 | -0.005 | -5 | 未降伏だった負側の初期載荷 |
| 9 | -0.030 | -12 | 負側降伏、ゼロ力位置は-0.018 |
| 10 | -0.024 | -6 | 負側からK1で除荷 |
| 11 | -0.018 | 0 | 負側ゼロ力位置 |
| 12 | 0.010 | 0 | 両側降伏後のスリップ区間 |
| 13 | 0.024 | 6 | 正側再載荷 |
| 14 | 0.040 | 13 | 最大点更新、正側ゼロ力位置は0.027 |

別試験として、未載荷状態から`0 → 0.030 → -0.030 → 0`の仕事は区間ごとの解析積分で`0.396 kN·m`となる。以後、同じ最大変形の内側だけを往復する閉経路は同じ枝を往復し、正味仕事は0となる。一般的なバイリニア弾塑性則のループ面積を期待値に使わない。

## 4. 公開入力の追加仕様

### 4.1 fix_nodeの自由度欄にオブジェクトを許可する

既存のケース・配列構造を維持し、非線形にする自由度だけオブジェクトを指定する。以下の入力断片に対応した。構造要素・基準荷重を含む完全な例は[slip-support-history.json](../examples/slip-support-history.json)。

```json
{
  "fix_node": {
    "1": [
      {
        "n": 2,
        "tx": {"type": "slip", "K1": 1000.0, "K2": 100.0, "delta_1": 0.01},
        "ty": 1,
        "tz": 1,
        "rx": 1,
        "ry": 1,
        "rz": 1
      }
    ]
  },
  "analysis_type": "material_nonlinear",
  "analysis_params": {
    "displacement_control": {
      "node": 2,
      "dof": "dx",
      "targets": [0.005, 0.03, 0.024, 0.018, 0.01, 0.025, 0.0, -0.005, -0.03]
    }
  }
}
```

この断片に構造要素・節点と非ゼロの基準節点荷重を加えて使用する。現行の変位制御は基準荷重の係数λも解く方式なので、`targets`だけでは解析入力として完結しない。

| fix_node欄 | 正規化入力・Pythonのdirection | 変位制御のdof | ばねの単位例 |
|---|---|---|---|
| tx / ty / tz | x / y / z | dx / dy / dz | K1・K2: kN/m、delta_1: m、F: kN |
| rx / ry / rz | rx / ry / rz | rx / ry / rz | K1・K2: kN·m/rad、delta_1: rad、F: kN·m |

数値0・1・その他、自由度欄の省略による自由支点は従来どおり。オブジェクト内のK1=1もばね剛性1として扱え、固定条件とは解釈しない。

### 4.2 正規化JSON・Python API

線形ばねの既存辞書は維持し、新たに`boundary_conditions.nonlinear_spring_supports`を追加した。

```json
{
  "boundary_conditions": {
    "nonlinear_spring_supports": {
      "2": {
        "x": {"type": "slip", "K1": 1000.0, "K2": 100.0, "delta_1": 0.01}
      }
    }
  }
}
```

Pythonには次の明示的なAPIを追加し、JSONと同じ定義型・検証を通す。

```python
model.add_slip_spring_support(
    node_id=2, direction="x", K1=1000.0, K2=100.0, delta_1=0.01
)
```

同一自由度の固定／強制変位／線形ばね／スリップばねの重複を拒否する。別自由度では混在可能。旧JSONと明示形式の併用では、既存の「明示restraintsが節点の拘束全体を置換する」規則を維持し、正規化後の競合を検査する。スリップばねの重複指定は黙って上書きしない。

未知のtype・未知キー・必須値不足・NaN/Inf・真偽値・不正な数値型・不存在節点・方向間違い・3自由度モデルの回転ばねは、節点・方向・入力位置が分かるエラーにする。正規化入力とPythonでも同じエラー条件にする。

### 4.3 対応範囲と互換性

- 解析種別が省略され、スリップばねが一つでもある場合は`material_nonlinear`を自動選択する。非線形梁がなくても動作させる。
- 明示的な`static`・`modal`との組合せは、初回は解析前に拒否する。自動でK1の線形ばねへ置き換えない。低水準Solverからの利用でも検査する。
- 構造要素は既存の材料非線形解析で許可されるものと組み合わせる。並進3方向、6自由度モデルの回転3方向、線形梁・JR梁・シェル・ソリッドとの混在を検証する。
- 純粋なばね則の試験は単体で行う。公開FemModelの「構造要素が必要」という現行制約は維持し、公開例には構造要素を含める。
- 支持地盤の移動、初期ギャップの独立指定、二節点間ばね、局所方向ばね、自由度間の連成、ばねだけの公開モデル、動的時刻歴は追加対象に含めない。

## 5. 何をどう変えるか

### 5.1 ばね則と支点の状態を分離する

新設候補`src/fem/nonlinear/hysteresis/slip.py`に、不変の`SlipSpringParams`、専用の`SlipSpringState`、純粋な応答評価を置く。状態には現在のδ・F・Kt、正負の最大経験点、各側の降伏経験、ゼロ力位置、現在の枝・進行方向を保持する。導出できる値を重複保持する場合は整合を保証する。

既存[base_hysteresis.py](../../src/fem/nonlinear/hysteresis/base_hysteresis.py)の「入力状態を変更せず候補応答を返す」方針は継承するが、JR専用の内部ループ・Nd状態をスリップばねへ流用しない。共通基底の大規模変更を前提にしない。

`BoundaryCondition`は線形・非線形支持ばねの**定義**を初期化時から持ち、`clear()`で両方を消去する。新設候補`src/fem/nonlinear/support_springs.py`に、節点・方向から全体DOFへの対応、試行応答、支点ごとのcommit／rollback／resetをまとめる。実行時状態は各解析に独立して作り、同じパラメータを使う節点間で共有しない。

### 5.2 全体釣合いへ支持ばねの力と接線を入れる

構造要素の内力を`f_element`、線形・非線形支持ばねの内力を合わせて`f_support`とし、

\[
R=\lambda P-f_{\mathrm{element}}(u)-f_{\mathrm{support}}(u;h_c),\qquad
K_t=K_{\mathrm{element},t}+K_{\mathrm{support},t}
\]

を解く。各スリップばねは該当DOFへF、対角成分へKtを加える。履歴を含むので`Kt * u`でFを代用しない。構造要素の内力へも同じ支持力を加えて二重計上しない。

`boundary_dofs.py`の境界条件処理に支持応答を渡し、`convergence.evaluate_equilibrium`と`equilibrium.py`の次の全経路を同じ確定履歴からの純粋評価へ接続する。`constrain`は支持項を再加算せず、拘束消去だけを担当する。

1. 荷重制御の残差・剛性、拘束処理、線探索の候補点評価。
2. 変位制御の残差と、自由度・λを含む拡大接線行列。
3. 収束尺度、ゼロ残差時のランク検査、結果metadataの釣合い残差。

線形支持ばねは従来の`F=k*u, Kt=k`を維持し、非線形ばねのない解析結果を変えない。支持自由度集合は固定・線形・非線形を区別して取得できるようにし、既存の線形辞書を読み取る呼出箇所の取りこぼしを確認する。

### 5.3 履歴の確定と失敗時の復元

Newton反復・線探索の候補点は、常に直前の収束状態から評価する。候補点が大きく降伏しても、その候補が不採用なら次の評価へ履歴を持ち越さない。

全体収束時だけ、梁と全支持ばねの状態を同じステップで確定する。未収束・局所評価例外・特異化では全支持ばねをrollbackし、最後に収束した変位・内力・λ・履歴だけを保持する。`run()`の再実行は初期履歴から開始する。

力評価と接線評価の呼出順、同じ点の反復評価、出力作成によって履歴が進まない設計にする。snapshotは確定状態のコピーとし、利用者が結果を変更しても解析中の状態や過去ステップに影響させない。

### 5.4 ゼロ剛性区間の扱い

スリップ区間では厳密に`F=0, Kt=0`を返す。微小剛性やペナルティで置換しない。

他の構造要素が全体剛性を持てば荷重制御でも解析できる。一方、支持が抜けて全体に機構が生じる場合や、力ゼロ区間で荷重から変位が一意に決まらない場合は、未収束／特異化として停止する。変位制御では拡大行列が正則なら追跡できるが、制御していない自由度の機構まで解消するとは限らない。

停止時の診断にはステップ、節点、方向、現在の枝・F・Ktを含める。残差がゼロでも必要なランク検査を省略して成功にしない。特に境界到着直後・同じ変位を繰り返すステップ・K2=0を試験する。

### 5.5 反力・梁端力・結果・保存

ばねのFを全体内力側の正方向で定義する。節点に作用する支持反力は`-F`であり、既存の`reaction_forces`の「構造要素内力−外力」という符号規約に合わせる。スリップばねしか設定されていない支持自由度も`_format_reactions`の出力対象にする。

`model.py`の`_recover_beam_end_forces`にも非線形支持DOFを渡す。現在のKtがゼロでも支持定義を見失わず、自由端と誤認して端力・反力を上書きしない。

各収束ステップと最終結果に`support_response`を追加した。節点ID・directionをキーとして、`type, deformation, force, tangent, branch, delta_max_pos, delta_max_neg, force_at_max_pos, force_at_max_neg, zero_pos, zero_neg`および降伏経験を出力する。負側値は符号付きに統一し、未経験側の仮想境界を実経験値と表示しない。

`solver_results.py`のsnapshot、final_result、metadata、`file_io.py`のJSON変換・保存、HTTPの通常／圧縮結果まで渡す。従来の節点変位・反力・梁端力は維持する。

モデル保存では正規化されたばね**定義**を保存する。読み直して同じ解析をすると同じ履歴が得られることを確認する。解析途中からの再開用checkpointは新設しない。FW3等、定義を保存できない形式は明示エラーとし、黙ってばねを脱落させない。metadataの入力ハッシュにも新定義が含まれることを確認する。

追加試験は既存の構成に合わせ、例として`tests/materials/test_slip_hysteresis.py`、`tests/solvers/test_slip_supports.py`、`tests/io/test_slip_support_input.py`、`tests/regression/test_slip_support_history.py`へ分ける。

必須の検証項目:

- **履歴則**: 正負単調、片側だけの降伏、弾性内反転、ゼロ到達前／ちょうどゼロ／ゼロ区間での再反転、最大点復帰・更新、大きな一増分、同一点反復、K2=0・K2=K1。枝内部の有限差分で接線を確認し、折れ点は片側値を確認する。
- **独立性**: 2.4の手計算値、初回仕事0.396、既存最大点内の閉経路仕事0、単位換算、変位経路の分割不変性。製品のばね評価関数から期待値を作らない。
- **全体釣合い**: 線形部材の有効剛性kbと支持ばねを持つモデルで`P = kb*u + Fslip(u)`を独立に解き、変位・支点反力・部材力を確認。回転系でも対応するモーメントの釣合いを確認する。
- **ゼロ剛性**: 他部材で安定するモデル、機構になるモデル、変位制御で追跡できるモデル、別DOFが機構になるモデルを分ける。局所Kt=0だけを理由に一律拒否しない。
- **履歴の寿命**: 採用されないNewton候補、線探索、複数ばねの一部だけが失敗する試行、ステップrollback、連続run、clear、結果辞書の変更。支点間・正負間の状態混入を検出する。
- **入力・混在**: 数値0／1／1未満／負の旧線形剛性、自由度省略、6方向、非連番節点、3/6自由度、複数支点ケースの選択、正規化形式との競合、線形梁・JR梁・シェル・ソリッドとの混在。選択していないケースを混ぜない。
- **公開経路**: 旧JSON・正規化JSON・Python・ファイル再読込・通常HTTP・圧縮HTTPの同条件結果を照合。明示static/modal、不正パラメータ、保存不能形式を拒否し、識別可能な診断を返す。
- **既存回帰**: `tests/solvers`、`tests/materials`、`tests/io`、梁関連の要素・統合・履歴回帰を先行確認し、実装完了時に全件を実行する。既存サンプルの参照値を新実装の出力で更新して合格にしない。

実装時の対象試験は`uv run --locked --extra dev pytest <対象>`、最終回帰は`uv run --locked --extra dev pytest`で実行する。結果は新規の`docs/report`記録へ残し、既存のJR・軸力変動の検証記録と区別する。

説明を更新する対象は、理論マニュアル7.19、[モデルの入力](../wiki/data-structures.md)、[非線形解析](../wiki/nonlinear-analysis.md)、[Python API](../wiki/python-api.md)、[ファイル形式](../wiki/file-formats.md)、[結果](../wiki/results.md)、対応範囲レジストリとする。
