# FEMPython ユーザーガイド

FEMPythonは、構造物に荷重をかけたときの変形、支点反力、部材の力や応力を計算するPython製の有限要素解析ライブラリです。梁・柱の骨組み、板・シェル、立体のソリッドを扱い、Python、JSONファイル、HTTP APIから利用できます。

このWikiは、リポジトリ内の現行実装を対象にしています。最初は小さな片持ち梁を解き、入力・出力の意味を確かめてから、ご自身のモデルへ進んでください。

## はじめて使う方へ

1. **[はじめに](getting-started.md)** — インストールし、片持ち梁を解析する。期待する変位・反力も確認できます。
2. **[要素と解析の選び方](elements.md)** — 梁、板、立体のどれでモデル化するか、どの解析が使えるかを選ぶ。
3. **[モデルの入力](data-structures.md)** — 節点・材料・荷重・支持条件と単位を定義する。
4. **[結果の読み方](results.md)** — 変位、反力、端力、応力、曲率を読み取る。
5. **[設計実務での利用手順](design-practice.md)** — 解析条件、釣合い、メッシュ感度、独立計算、保存資料を照査する。

## 何を調べられるか

| 調べたいこと | 選ぶ解析・要素 | 主な結果 |
|---|---|---|
| 梁や柱がどれだけたわみ、どこに力がかかるか | 線形静解析 `static`、梁要素 | 変位、回転、反力、軸力・せん断力・曲げ・ねじりの端力 |
| 床板や壁の変形、上下面の応力 | `static`、三角形・四角形シェル | 変位、応力・ひずみ、断面合力、辺の合力 |
| 厚みのある立体内部の応力 | `static`、一次・二次ソリッド | 変位、積分点の応力・ひずみ |
| RC部材などの剛性低下や繰返し載荷の履歴 | 材料非線形解析 `material_nonlinear`、非線形梁 | 各載荷段階の変位・反力・端力・中央断面曲率 |
| 構造物が振動する周期と形 | 固有値解析 `modal` | 固有値、振動数、周期、モード形 |

固有値解析は要素の質量行列を必要とします。通常の`wedge`経路など、未対応の組合せがあります。[対応表と制約](elements.md)を確認してください。

## 利用前に押さえること

- **1回の解析は1つの荷重条件です。** `load`に複数ケースがあるJSONは、先頭のケースを選んで解析します。全ケースが自動で返るわけではありません。[ケースごとに実行する例](examples.md)を用意しています。
- **単位は入力全体で統一します。** 自動の単位変換はありません。Wikiの最初の例はN・mを使い、変位はm、モーメントはN·mで読みます。
- **材料非線形解析は小変位・小回転を前提にします。** 非線形則は各梁要素の中央断面に置きます。大変形、座屈、軸力と曲げの相互作用、破断の解析ではありません。
- **時刻歴の地震応答、熱伝導、幾何学的非線形解析は公開解析経路にありません。** 温度変化による梁の伸縮を静解析する機能はあります。
- **モデル規模と精度は個別に確認します。** 66節点や24荷重ケースなど、過去のサンプル件数は製品の上限ではありません。節点が増えたことだけでは精度を保証できません。
