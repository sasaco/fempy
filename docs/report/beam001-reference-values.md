## 正解値が対応するモデル

現JSONの小変位・せん断変形なし・部材中央断面で非線形性を評価するモデルの数学的な正解値。
外部JRソフトの出力値ではない。実装の解析結果を転記して作った値でもない。
`tests/beam001_reference_values.py` はFEMコードをimportせず、Decimalの50桁演算で
釣合い・骨格の逆算・柔性の積分から値を算出し、最後にJSON数値へ変換する。

- 長さm、力kN、モーメントkN·m、変位m、回転rad、曲率1/m。
- 節点1〜4のy座標は −5、−0.2、−0.1、0。節点4は固定。
- 段階sの節点1のX荷重は `F = 1000 × s / 100 = 10s`。
- 各部材の `E Iz = 26500000 × 1000 = 26500000000`。
- 両材料のG省略により全3部材の`shear_correction=false`。せん断変形項は0。
- 部材2のみ非線形。単調載荷なので除荷係数βは今回の値に影響しない。

## 計算式

部材i端とj端のy座標をyi、yj、長さをLとし、固定端側から部材3、2、1の順に計算する。
中央曲げモーメントは `M = −F ((yi+yj)/2 + 5)`。
線形部材1、3の曲率は `κ = M/(E Iz)`。

非線形部材2では `m = |M| = 4.85F` とし、負の曲率を次式で求める。

```text
m ≤ 1000:        κ = −m × 0.00001 / 1000
1000 < m ≤ 3000: κ = −[0.00001 + (m−1000) × 0.00009 / 2000]
3000 < m < 5000: κ = −[0.0001  + (m−3000) × 0.0009  / 2000]
```

固定節点4の変位と回転を0とし、各部材について以下を適用する。

```text
θi = θj − Lκ
uxi = uxj + L(θi+θj)/2 + F L³/(12 E Iz)
```

最後の項は中央断面モデルが保持する弾性のモーメント勾配による柔性。
Gを明示してせん断変形を有効にした部材では、さらに`F L/[G (5/6) A]`を加える。
部材全長で非線形曲率を連続積分する別モデルの解とは区別する。
X変位とZ回転以外の節点変位は0。

反力は全体座標系で節点4の `tx = −F`、`mz = −5F`、他成分0。
`fsec` は部材局所座標の断面力表記であり、各部材の
`fyi = fyj = −F`、`mzi = F(yi+5)`、`mzj = F(yj+5)`、他成分0。
元ダミー値の符号や方向は正解値の根拠にしない。
