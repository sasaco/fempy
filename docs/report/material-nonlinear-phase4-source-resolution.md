### 面内回転の余分な自由度とDKTの精度

以前の回転差だけのシェル安定化には、6剛体モード以外に独立した一定drill回転が残っていた。
そのため、節点1の6自由度を固定しても面圧試験が特異になった。
変位場のspinと独立回転を結ぶ拘束エネルギー
`(1/2) * 0.001 * G * t * integral((rz - (dv/dx-du/dy)/2)^2 dA)`へ変更した。
[Hughes・Brezziの独立回転変分形式](https://doi.org/10.1016/0045-7825(89)90124-2)を根拠とする。
地盤への仮想ばねや剛性対角成分のシフトは加えていない。
この安定化エネルギーは物理的ひずみエネルギーと別に出力する。
剛体6モード、座標回転、定ひずみ、spinとの差による独立エネルギーを検証した。

DKTでは形状補間・局所座標・剛性積分をDecimal 50桁で評価し、丸め成分を静解析へ渡す。
主成分のみの公開剛性行列との整合を維持し、同形状・材料の128組をキャッシュする。
これにより、Tri1のほぼ相殺する微小応力で残った1.77e-10の差も厳密許容範囲へ収まった。
薄板DKTの横せん断変形を追加したものではない。

### シェル出力の定義と限界

公開結果の`shell_results`は **実要素ID** をキーにする。`node_ids`と`local_basis`を同梱する。

- `raw_result`: node/elemのStrain1/2、Stress1/2、Energy1/2。1は節点順序の法線方向z=+t/2、2はz=-t/2。
  成分順は全体座標のxx,yy,zz,xy,yz,zx、せん断ひずみは **テンソルせん断（γ/2）**。要素値は面積平均。
  Energy1/2はエネルギー密度。V0にある下面平均を上面から再代入する誤りは移植しない。
- `strain_energy`: 膜・曲げ・横せん断の物理エネルギーの体積積分。
  `drilling_energy`は正則化の寄与。両者の和と0.5*u^T*K*uの一致を検証。
- `resultants`: 局所座標の膜力[Nxx,Nyy,Nxy]、曲げ[Mxx,Myy,Mxy]、横せん断[Qx,Qy]の面積平均。
- `edge_resultants`: 全辺を要素ごとに保持。i端は前節点、j端は現節点。外向き法線と、
  全体座標[Fx,Fy,Fz,Mx,My,Mz]のi_end/j_end整合節点力を出力。共有辺を他要素の値で上書きしない。
  物理的な断面の表面力であり、旧`shell_fsec`の仮想梁への分解とは同一視しない。
- `stress`/`strain`は上面の表示用辞書。`strain.exy`は工学せん断γ。
  横せん断応力は剛性と整合する(5/6)Gγであり、自由表面でゼロになる3次元応力回復ではない。

平面、小変位、小回転、線形弾性シェルが対象。三角形の薄板ロッキングは継続課題。

### Hexa1・Wedge1

`sampleBendHexa1` と `sampleBendWedge1` は、元の `.out` の全入力エコーに対して、
節点・要素接続・材料E/ν・節点荷重・拘束が一致する。等方ソリッドの静的構成式はE/νを用い、
独立指定Gや密度をこの一致から検証済みとはしない。
全620節点×6変位成分の原出力と現実装は既存の厳密比較を通る。
さらに反力と原荷重の全体合力・合モーメントを照合した（受入絶対値1e−8、1e−7）。

一方、埋込JSONの変位は全成分で原出力の1000倍になっている。
例えばHexa1の節点10dxは、原出力 `−0.016960342320169023` に対しJSONは `−16.960342320169023`。
全成分を1000で割った診断比較は原出力と一致する。Eや入力荷重を1000倍変える根拠はない。
原出力には個々の支点反力参照がなく、JSONには `reac/fsec/size/shell_fsec/shell_results` の参照もない。
そのため、変位の倍率差の原因は確定したが、全出力を要求する旧サンプル試験自体は引き続き失敗する。
現ソルバーの反力を期待値へ転記して補うことはしない。
