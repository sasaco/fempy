# 第4段階: 既存サンプルの計算・入力・参照の切り分け

2026-09-08。対象は[handoff](../plans/material-nonlinear-phase4-handoff.md)の旧梁22・シェル14・bend7の失敗。
**計算不具合を修正し、原資料との照合を追加したが、旧43件の完全解消と第4段階全体の完了には至っていない。**
既存サンプルの入力・埋込参照、比較許容値、比較項目を変更して成功扱いにはしていない。

## 実装と独立検証

| 対象 | 修正前の問題 | 修正・根拠 |
|---|---|---|
| シェル剛性 | 剛体並進・回転に内力が発生。垂直面はXY Jacobianに依存。縮退形状でも簡易剛性を返す | 局所面基底で組み立て、並進・物理回転を全体座標へ変換。対角シフトと剛性フォールバックを撤去。縮退・非平面・逆転Jacobianを明示拒否 |
| 曲げ・せん断の回転 | rxとryの役割が逆 | 右手系で `u(z)=u0+z*ry`, `v(z)=v0-z*rx`、`gamma_xz=w,x+ry`, `gamma_yz=w,y-rx` を使用 |
| 四角形のせん断 | 中央1点積分による余分なゼロエネルギーモード | MITC4の辺中央の共変せん断補間を使用し、2×2点で積分。定曲率エネルギー、板厚・分割・配置を変えた一定モーメント片持ち板で照合 |
| ドリリング | 各節点の法線回転に対地ばねが存在 | V0と同様に節点間の回転差のみを正則化。一定ドリリングの零モードを維持。これは物理的なドリリング剛性ではない |
| 面圧 | V0のF1/F2を辺として解釈し、圧力×辺長/2を載荷。全体XYに依存、不正面もフォールバック | V0の表裏面へ修正。`f_i=integral(N_i*p*n dA)` を面積積分。F1は節点順序の法線側、正の面圧は内向き、F2は反対。合力・モーメント・全節点成分・回転配置を検証 |
| 線形梁の端力 | 大きな剛性と剛体移動成分の積が相殺し、端力に桁落ち | 分布ばねのない要素では剛体運動を差し引いてから内力評価。Newton内力と断面力に同じ評価を使用。ゼロへの丸め・クリップはしない |
| 線形梁の区間剛性 | ばねのないBE梁にも条件の悪い状態遷移の行列指数を使用 | 同じ境界値問題の厳密多項式解を使用。`w=x^3` の剛性仕事と荷重仕事、合力・合モーメントで検証。分布ばね・T梁の状態遷移は維持 |
| 接続のないモデル | 要素がないままゼロ行列を解き、解析方式によって成功や特異エラーになる | `FemModel.run` で要素接続不足の入力エラーに統一。過去のresultsも消去 |

最初のシェル運動学18件は **18失敗→18成功**。
面圧12件は **11失敗・1成功→12成功**。接続不足3件は **3失敗→3成功**。
追加した試験は合計69件。シェルの一定曲率・全体解析、梁の仕事・内力、原資料の読込・差分・欠落検出を含む。

特に `test_pressure_vs_concentrated_load_equivalence` の「実際の実装値250、許容10%」を撤去し、
1 m²に1000の面圧を与える全4節点のZ荷重−250、合力−1000、合モーメント(−500,500,0)を検証する。
これはサンプル参照の削除や許容値緩和ではなく、V0の面定義と積分式による試験の訂正である。

四角形の補間の根拠は [Ko, Lee, Bathe (2016), §2, 式(5)](https://web.mit.edu/kjb/www/Principal_Publications/The_MITC4_plus_shell_element_and_its_performance.pdf)。
ここで採用したのは平面のMITC4横せん断補間であり、同論文のMITC4+全機能ではない。
面圧の原資料は `docs/v0/src/ShellElement.js` の `TriElement1/QuadElement1.prototype.border`。
`borderEdge` は別APIであり、圧力の表裏面と区別する。

## 原資料から確定したこと

`tests/phase4_source_evidence.py` を追加し、全ケース監査に組み込んだ。
`.fem/.out` のSHA256、節点・材料・接続・荷重・拘束の比較、参照節点数、参照倍率ごとの不一致数、
計算結果と原資料の変位比較を[監査JSON](material-nonlinear-phase4-sample-audit.json)に保存する。
原資料の入力エコーがなければ未確認のままとし、同名ファイルだけで同じモデルとは判定しない。
比較器は従来の `rel=1e-8, abs=1e-10` をそのまま使用する。

### Hexa1・Wedge1

`sampleBendHexa1` と `sampleBendWedge1` は、元の `.out` の全入力エコーに対して、
節点・要素接続・材料E/ν・節点荷重・拘束が一致する。等方ソリッドの静的構成式はE/νを用い、
独立指定Gや密度をこの一致から検証済みとはしない。
全620節点×6変位成分の原出力と現実装は既存の厳密比較を通る。
さらに反力と原荷重の全体合力・合モーメントを照合した（受入絶対値1e−8、1e−7）。

一方、埋込JSONの変位は全成分で原出力の1000倍になっている。
例えばHexa1の節点10dxは、原出力 `−0.016960342320169023` に対しJSONは `−16.960342320169023`。
全成分を1000で割った診断比較は原出力と一致する。Eや入力荷重を1000倍変える根拠はない。
原出力には個々の支点反力参照がなく、JSONには `reac/fsec/size/shell_fsec/shell_results` の参照もない。
そのため、変位の倍率差の原因は確定したが、全出力を要求する旧サンプル試験自体は引き続き失敗する。
現ソルバーの反力を期待値へ転記して補うことはしない。

### bendの接続不足・不完全な原出力

Hexa2・Tetra2・Wedge2・Tri1のJSONには要素接続がない。元の `.fem` には接続が存在する。
単なる線形ソルバーの特異性ではなく、移行データの欠落である。
2次ソリッドの要素種別・節点順序の実装と検証、Tri1のシェル接続の復元が別途必要。
未実装要素を1次要素に読み替えたり、存在する節点を無荷重として消去したりしない。

Tetra1の `.out` は620節点中10節点しか出力しておらず、610節点の参照がない。
入力エコーもない。ヘッダのモデル名・最大変位だけでは現在の荷重・拘束との同一性を証明できない。
不足分を現在の計算結果から生成しない。

### 梁の入力条件

監査は荷重ケースで実際に選択された `element/fix_node/joint/fix_member` を使用する。
2D_Sample13のケース1は材料ケース3を選び、材9・12のIzが0である。
表示用の材料ケース1の非ゼロIzを見て「正の剛性なのに計算が壊れた」と判定しない。
3D_Sample01/04/05にもゼロ断面諸元がある。ゼロ自体は必ずしも不正ではないので、
対象モードの荷重・拘束・生成節点と併せて意図を確定する必要がある。
旧 `get_secMatValues` のゼロ→1e−9補完は復活させない。

`src/app/components/member.py::get_coordinateByLength` は
`components/node.py::get_coordinate` で生成座標を1mm単位、ROUND_HALF_UPで丸める。
現在の分割は正確な共線位置を使う。3D_Sample10の斜め部材15の集中荷重点などは、
旧丸めにより座標・区間長が変わる。監査に位置差と具体例を記録する。
これは旧コードとの入力モデル差の証拠であり、出典不明の全埋込結果が同コード製という証明ではない。
旧丸めを現実装へ戻して値を合わせる変更は行っていない。

2D_Sample06には存在しない部材39への着目点があり、`unknown_notice_member` として記録する。
診断自身がKeyErrorで数値監査を止めないことを試験した。
3D_Sample07の非ゼロ荷重mark=0は未定義の入力として残る。

### shellPressureTest1

現入力は節点1の並進3成分だけを拘束する。節点1を中心とする剛体回転が自由である。
Y軸回転 `u=ey×x, rotation=ey` は拘束を満たし、修正後の剛性による内力はゼロだが、
1000の表面圧による外力仕事は500でゼロでない。この入力に一意な静的釣合い解はない。
人工剛性撤去後のrank不足拒否が正しいことを独立試験で確認した。
支点意図の確認が必要であり、都合のよい追加拘束をサンプルへ書き込んでいない。

## 適用範囲と残る実装

新しいシェル剛性は平面・小変位・線形弾性に限定する。
3節点三角形は3点積分のMindlin型であり、薄板のせん断ロッキングの改善は未完了。
V0三角形の高次曲げ補間と同一ではない。
四角形でも任意の歪み・曲面・非平面への精度保証はしていない。
ドリリング差分正則化は残り、要素単体の零モード数は物理的剛体6＋一定ドリリング1。
今回の試験は正則化係数に対する一般的な解の独立性を保証しない。

旧 `shell_results`（節点上下表面、中央応力・エネルギー等）と `shell_fsec`（辺ごとの専用表記）は
未実装のままであり、膜応力出力だけで代用していない。
これらと三角形の定式化、2次ソリッドを別の実装課題として追跡する必要がある。
梁の残る不一致は、特異・条件数、分布ばね、参照数値誤差・入力丸め等の個別検証が残る。
位置丸めが見つかったことを理由に、すべて参照側の問題と断定しない。

## beam001の変更と回帰の区別

開始時点は **849成功・44失敗・警告1件（47.90秒）**。
旧43件に加えて、beam001はG省略後のゼロ端モーメントの数値誤差で失敗していた。
今回の剛体運動を除いた端力評価でも、この厳密なゼロ端力条件を全段階では満たせていない。
比較許容値の緩和や結果のゼロへの丸めで解決済みにしていない。

作業中にユーザーがbeam001の `delta_3` を `0.001` → `0.0010103` へ変更した。
この変更は保持し、既存の埋込参照と固定の手計算値を書き換えていない。
第3枝に到達する段階62以降は、旧骨格用の変位参照と新入力が異なる。
したがって現workspaceのbeam001参照失敗と、開始時点の端力丸め誤差を区別する。
JR履歴則・NonlinearBarElementの製品コードは本変更で変更していない。
