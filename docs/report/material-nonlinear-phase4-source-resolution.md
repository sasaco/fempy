### 変位の補正分を保持した静解析

`precision.py`に積の丸め誤差・補償内積・TwoSum更新を実装。
疎行列の直接解を、剛性を変更せず補償残差で反復補正する。
Python 3.13以降では`math.fma`、3.11/3.12ではDecimalを用いる。同じ演算を用いる代替経路を試験済み。
純線形梁モデルは、さらに各要素の構成則と支持ばねによる自由節点残差を検査し、補正する。
分布ばね付き要素の剛性積、局所座標変換、長さ×回転の積の誤差も保持する。

公開`displacement`は従来の倍精度値。小さい補正成分を同じDOF順序の`displacement_correction`として別保存する。
梁端力と支点反力はこの補正を含む構成則から計算し、その後に既存の自由枝釣合い回復を行う。
端力回復の許容値、比較許容値、人工剛性、入力の区間長は変更していない。
補正処理は静解析が対象で、非線形の履歴則・Newton解法は変更していない。

2D_Sample04のケース1/2は以前は端力回復の検査で停止していたが、現在は計算と厳密比較へ進む。

### シェル出力の定義と限界

公開結果の`shell_results`は **実要素ID** をキーにする。`node_ids`と`local_basis`を同梱する。

- `raw_result`: node/elemのStrain1/2、Stress1/2、Energy1/2。1は節点順序の法線方向z=+t/2、2はz=-t/2。
  成分順は全体座標のxx,yy,zz,xy,yz,zx、せん断ひずみは **テンソルせん断（γ/2）**。要素値は面積平均。
  Energy1/2はエネルギー密度。V0にある下面平均を上面から再代入する誤りは移植しない。
- `strain_energy`: 膜・曲げ・横せん断の物理エネルギーの体積積分。
  `drilling_energy`は正則化の寄与。両者の和と0.5*u^T*K*uの一致を検証。
- `resultants`: 局所座標の膜力[Nxx,Nyy,Nxy]、曲げ[Mxx,Myy,Mxy]、横せん断[Qx,Qy]の面積平均。
- `edge_resultants`: 全辺を要素ごとに保持。i端は前節点、j端は現節点。外向き法線と、
  全体座標[Fx,Fy,Fz,Mx,My,Mz]のi_end/j_end整合節点力を出力。共有辺を他要素の値で上書きしない。
  物理的な断面の表面力であり、旧`shell_fsec`の仮想梁への分解とは同一視しない。
- `stress`/`strain`は上面の表示用辞書。`strain.exy`は工学せん断γ。
  横せん断応力は剛性と整合する(5/6)Gγであり、自由表面でゼロになる3次元応力回復ではない。

平面、小変位、小回転、線形弾性シェルが対象。三角形の薄板ロッキングは継続課題。
2次ソリッドは静的等方弾性の原資料と多項式パッチで検証した。曲がった中間節点・強い歪み・曲面境界や
任意複合モデルでの精度保証、幾何学的非線形・材料非線形ソリッドは含まない。
