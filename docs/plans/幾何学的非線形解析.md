# 幾何学的非線形解析の実装計画（バー要素限定）

## 概要

理論マニュアルPDF（セクション6, 23-24ページ）に基づき、バー要素に幾何学的非線形解析を実装する。

## 理論的背景（PDFより）

大変形解析では、要素の長さと方向の変化を考慮し、局所座標系を各ステップで更新する必要がある：

1. **回転行列Rα**: y軸周りの回転 (sin(α), cos(α))
2. **回転行列Rβ**: z軸周りの回転 (sin(β), cos(β))
3. **合成変換**: Rd = RβRα
4. **ねじり補正**: Rγ (平均ねじり角 γ = (γi + γj)/2)
5. **最終変換**: Rm = RγRdR（Rは初期変換行列）

## アルゴリズムフロー

```
1. 初期化
   ├── 初期変換行列と初期長さを保存
   └── u_total = 0

2. 荷重増分ループ (step = 1 to n_steps)
   │
   ├── 荷重係数計算: λ = step / n_steps
   ├── 外力計算: F_ext = λ * F_total
   │
   └── Newton-Raphson反復 (iter = 1 to max_iter)
       │
       ├── 要素構成更新
       │   ├── 変形座標から変換行列更新（PDF理論）
       │   └── 要素長さ再計算
       │
       ├── 内力計算
       │   ├── 各要素: f_int = K_local @ u_local
       │   └── 軸力抽出（幾何剛性用）
       │
       ├── 残差計算: R = F_ext - F_int
       │
       ├── 収束判定: ||R|| / ||F_ext|| < tol
       │   └── 収束 → 次のステップへ
       │
       ├── 接線剛性組み立て
       │   ├── K_elastic（更新された構成から）
       │   └── K_geometric（軸力から）
       │
       ├── 変位増分解: KT @ du = R
       │
       └── 更新: u_total = u_total + du

3. 結果出力
   ├── 最終変位
   ├── 荷重-変位履歴
   └── 収束履歴
```
