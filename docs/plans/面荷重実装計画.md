## 1. 目的

前身 `FrameWeb` の `inf_panel`、`line`、`load_inf` で表していた既知配置の線荷重・面荷重を、
FrameWeb3 の線形静解析へ導入する。標準経路では分布荷重を整合等価節点荷重へ変換し、
通常の節点荷重・部材荷重と同じ一つの荷重ケースとして解析する。

実装完了時には、次を満たす。

- 旧形式 JSON の `inf_panel`、`line`、`load[*].load_inf` を読める。
- 線荷重・面荷重の合力と一次モーメントを保存した節点荷重ベクトルを生成できる。
- 既知の一荷重配置は、パネル節点数に比例する単位荷重解析を行わず、原則一回で解ける。
- 既存の `FemModel`、JSON ファイル、HTTP の各入力経路で同じ結果を返す。
- 対象外の解析・不正な幾何・外挿を、解析開始前に理由と ID を付けて拒否する。
- 節点変位、支点反力、梁端力、シェル結果へ同じ荷重が反映され、再解析で荷重が重複しない。

## 2. 対象範囲

### 2.1 最初に提供する範囲

- 解析種別は `static` のみとする。
- 旧形式の座標・符号は、全体 XY 平面、全体 `+Z` 方向、`P11` などをその倍率として扱う。
- 一本の折れ線上で、始点・終点強度を折れ線長に沿って線形補間する線荷重を扱う。
- 二本の折れ線に挟まれた領域で、対応する端部強度から線形補間する面荷重を扱う。
- 一つの荷重ケース内にある複数の `load_inf` は加算する。
- パネルには、既存シェル要素の集合または既存構造節点IDを頂点とする明示載荷三角形を使う。
  載荷三角形は補間専用で、剛性・材料・板厚を追加しない。シェルを持たない梁モデルも対象とする。
- 初回のパネル外周・載荷帯は単純・凸・穴なしとする。非凸外周と非空の穴は明示的に拒否する。
- T3の重心座標とQ4の双一次形状関数を使い、荷重場を含む被積分関数に応じた求積を実装する。
  平面Q4の歪みはそれだけでは対象外にせず、逆写像と求積の収束を検証する。

### 2.2 後続段階で提供する範囲

- 局所平面、全体方向ベクトル、面法線方向を明示する一般座標モード。
- 非凸外周と穴を持つ領域、および既存構造節点と一致しない独立載荷節点からの保存的写像。
- 曲面上の面荷重、曲線上の線荷重、位置ごとに変化する面法線と面積 Jacobian。
- 前身の RBF・無制約 Delaunay・台形則を再現する、明示選択の旧値互換モード。
- 多数の荷重配置・応答を扱う場合の影響値または随伴解のキャッシュ。

### 2.3 対象外

- `material_nonlinear`、`modal` への影響荷重の適用。
- 道路橋示方書、Eurocode、AASHTO 等の設計活荷重モデルそのもの。
- 車両・車線配置の生成、最不利位置探索、最大・最小包絡、動的増幅、接地面への荷重分散。
- 既存のシェル `pressure` 入力の置換。`pressure` は要素面圧、今回の機能は載荷領域上の
  線・面荷重であり、入力責務を分けたまま共通の求積部品だけを利用する。
- 旧 `FrameWeb` の数値を、正解値が未確定のまま標準方式の受入基準にすること。

## 4. 入力契約

### 4.1 旧形式の受入契約

理論文書に示した既存キーを保持する。

```json
{
  "inf_panel": {
    "1": {"nodes": ["1", "2", "3", "4"], "elements": ["10"]}
  },
  "line": {
    "1": {"position": [{"x": 0, "y": 1}, {"x": 10, "y": 1}]},
    "2": {"position": [{"x": 0, "y": 3}, {"x": 10, "y": 3}]}
  },
  "load": {
    "1": {
      "inf_panel": 1,
      "load_inf": [
        {"L1": "1", "P11": 10, "P12": 20,
         "L2": "2", "P21": 30, "P22": 40}
      ]
    }
  }
}
```

`elements` は FrameWeb3 の標準方式で追加する任意項目で、旧形式では旧 `shell` 名前空間のIDを指す。
`file_io.py` の旧シェルID→内部要素ID専用マップで解決し、単なる整数化で内部要素を検索しない。
`member=1` と `shell=1` の共存、保存後の内部ID参照を契約テストに含める。

`triangles: [[1, 2, 3], [1, 3, 4]]` も追加でき、各頂点は `nodes` に含まれる既存構造節点IDとする。
`elements` と `triangles` の非空指定は排他とする（正規化保存では使わない側を空配列にする）。
載荷三角形からはその3節点の並進DOFへ重心座標で直接配分する。
シェル要素を追加したり、梁へ要素分布荷重を追加したりしない。

両方を省略した場合は、`nodes` の部分集合だけで
構成される既存シェル要素を抽出し、その結合領域が一意なら採用する。シェル要素から接続を
復元できない節点集合を、標準方式で無制約 Delaunay 分割してはならない。その場合は
「明示トポロジーが必要」として拒否する。旧入力に `triangles` を追加すれば梁モデルも標準方式で
扱える。節点集合だけからの旧推論を必要とする場合だけ、将来の旧値互換モードで別扱いにする。

現行の旧形式読込が先頭荷重ケースを一つ選ぶ契約は、この変更では拡張しない。選択されたケースの
通常荷重と `load_inf` を同時に組み立てる。別荷重ケースの `load_inf` を混入させない。

### 4.2 一般形式の正規化モデル

内部型は少なくとも次を保持する。

- `SpatialLoadPanel`: ID、構造節点ID、シェル内部要素IDまたは載荷三角形接続、穴、幾何許容値。
  外周は接続から復元する。穴は初回では空のみ許可し、局所基底の公開指定は第5段階とする。
- `SpatialLoadPath`: ID、順序付き3次元点、累積弧長。
- `SpatialLoad`: 荷重ID、パネルID、一本または二本のpath ID、それぞれの始終点強度。
  初回の方向は全体 `(0, 0, +1)` 固定。`LoadDirection` と互換モードの公開は後続段階とする。
- `SpatialLoadContribution`: 全体DOF荷重、要素別寄与、合力、原点回りモーメント、求積統計。

新形式JSONはトップレベルの `spatial_loads` に次の形で保存する。要素参照は内部要素IDとする。

```json
{
  "spatial_loads": {
    "panels": [{"id": 1, "nodes": [1, 2, 3, 4], "triangles": [[1, 2, 3], [1, 3, 4]]}],
    "paths": [{"id": 1, "points": [[0, 1, 0], [10, 1, 0]]}],
    "loads": [{"id": 1, "panel_id": 1, "path_ids": [1], "end_intensities": [[10, 20]]}]
  }
}
```

Python APIは `FemModel.set_spatial_loads(SpatialLoadDefinitions(...))` とし、同じ不変定義型を使う。
旧形式アダプタは選択ケースが使うパネル・ラインを取り込み、`load_inf` の順序から荷重IDを1始まりで
付ける。選択ケースの旧荷重と新 `spatial_loads` の併記は曖昧な二重入力として拒否する。
IDの正規化後の重複、欠落参照、未知キーを拒否する。旧パネル・ラインの表示用 `name` は解析定義外とする。
保存時には正規化済み定義を欠落なく出力し、
保存→読込→再解析で結果が変わらないことを契約にする。
`.fw3` には空間荷重の保存構文がないため、定義を持つモデルはファイルを開く前に拒否しJSON保存を案内する。
入力実装から荷重組立の接続までの移行中は、読込・保存は可能でも解析は未対応として行列組立前に拒否する。

### 4.3 入力検証

解析行列の組立前に、次を一括検証する。最初の不正値を黙って補正せず、種類と ID を含む
`ValueError` を返す。

- 参照するパネル・ライン・節点・要素 ID が存在する。
- 座標、強度、方向、許容値が有限で、方向ベクトルのノルムがゼロでない。
- ラインは二つ以上の異なる点を持ち、長さゼロ区間、重複点、自己交差がない。
- 面荷重の二本のラインは5.3の対応規則を満たし、セルの反転・重複・交差がなく領域を閉じられる。
- パネル要素は連結し、反転・退化要素を含まず、指定した外周・穴と整合する。
- 平面モードの節点は、モデル寸法から定める相対許容値内で同一平面上にある。
- ラインと面荷重領域がパネル外へ出ず、外挿を必要としない。
- 同じ構造要素をパネル内で重複指定しない。
- `material_nonlinear` と `modal` は空間荷重が一件でもあれば、対応可否検査で明示的に拒否する。

幾何許容値はパネル代表長さ `L` に対して `eps_l = max(absolute_length, relative_length * L)` とする。
初期値はそれぞれ `1e-9`（モデルの長さ単位）、`1e-9`（無次元）。各値は有限かつ非負で、両方ゼロは拒否する。
面積・Jacobianの退化判定は `L^2`、逆写像残差は `L`、自然座標の判定は無次元で正規化する。
力の比較尺度は `integral(abs(q), ds)` または `integral(abs(p), dA)`、モーメントはその力尺度と
代表腕長から導出し、力・モーメントそれぞれの絶対許容値と相対許容値を使う。正負の相殺で尺度をゼロにしない。
許容値の管理場所は共通化するが、異なる次元に同じ数値を流用しない。荷重値・座標は入力時に丸めない。

## 5. 数値実装方針

### 5.1 共通処理

1. パネルを局所2次元座標へ写し、構造要素または載荷三角形との接続を作る。
2. ラインをパネル要素境界との交点で分割する。各小区間は一つの要素だけに属させる。
3. 面荷重領域をパネル要素ごとにクリップし、積分対象の三角形へ分ける。
4. 各積分点で荷重強度、荷重方向、シェル形状関数または載荷三角形の重心座標、積分写像のJacobianを評価する。
5. `N_i * q * J_l` または `N_i * p * J_s` を積分し、節点の並進自由度へ加算する。
6. 同じ積分点から入力分布の合力・一次モーメントを独立に積分し、節点荷重側の値と比較する。
7. コンパイル結果を `Solver.assemble_load_vector()` の一回の呼出しで既存荷重へ加算する。

載荷三角形では補間先を3頂点の構造節点に固定し、構造要素への再探索・追加写像は行わない。
シェルをクリップして作る三角形は求積領域にすぎず、Q4形状関数をT3へ置き換えない。
物理座標の三角形面積を積分重みに含めた場合、シェルJacobianをさらに掛けて二重計上しない。

入力辞書、`BoundaryCondition.loads`、メッシュ接続を変換処理中に書き換えない。解析を二回実行しても
等価節点荷重が二重加算されない、純粋な `definition + mesh -> contribution` の契約にする。

### 5.2 線荷重

- 荷重強度はライン全長に対する累積弧長で `P11` から `P12` へ補間する。
- 各小区間でT3補間×線形強度は二次、affine Q4補間×線形強度は高々三次なので2点Gaussで厳密積分する。
  歪んだQ4の逆写像は一般に非多項式なので、高次則と区間細分化で収束を確認する。
- 四角形要素では積分点の自然座標を逆写像し、要素内判定と残差を検査する。
- 区間が要素境界上にある場合は一方だけへ所有させ、二重積分を防ぐ決定規則を設ける。
- 点順序と始終点強度を同時に反転した結果は、ビット一致を必須にせず規定許容誤差内で一致させる。

### 5.3 面荷重

二本のラインをそれぞれ正規化累積弧長 `s∈[0,1]` で `a(s), b(s)` と表す。端点間距離二乗和
`|a(0)-b(0)|^2 + |a(1)-b(1)|^2` と逆向き対応の値を比較し、小さい方へ第2ラインとその端部強度を
同時に整列する。幾何許容値内で同値なら「対応が曖昧」として拒否する。入力定義自体は書き換えない。

両ラインの折点の `s` を統合して各区間をセル化し、横断座標 `t∈[0,1]` に対して

```text
x(s,t) = (1-t)*a(s) + t*b(s)
p1(s)  = (1-s)*P11 + s*P12
p2(s)  = (1-s)*P21 + s*P22
p(s,t) = (1-t)*p1(s) + t*p2(s)
```

と一意に定義する。セルのJacobianがゼロまたは符号反転する場合、セル同士が内部で重なる場合、
境界が交差する場合は拒否する。初回はパネル外周と載荷帯の外周とも単純・凸・穴なしを検証する。
各セルとパネル要素の共通部分を三角形化し、物理点からセルの `(s,t)` を逆写像して強度を評価する。
荷重場の折点境界でも分割し、構造メッシュや求積三角形の対角線によって荷重場を再定義しない。

求積は `N_i*p*J` 全体で決める。T3×物理座標一次荷重に限定すれば三角形3点則で厳密だが、
affine Q4でも一次荷重との積は三次、上記横断補間ではT3でも二次精度では不足し得る。
非多項式の場合は三角形のDuffy写像による4×4・8×8 Gaussの比較と再帰4分割を使い、節点荷重の
各成分・合力・一次モーメントの推定誤差を領域全体の許容値内に収める。細分化上限で未収束なら
荷重ID・パネルID付きで拒否する。比較則の一致だけを数値正解にせず、独立高精度積分との試験も行う。
非凸・穴のwinding検証とクリッピング拡張は第5段階。凸包への置換は全段階で禁止する。

### 5.4 荷重方向と座標系

- 旧形式は全体 `+Z` を固定し、正の強度をその向きの荷重として扱う。
- 一般モードの全体方向ベクトルは入力時に正規化し、強度だけが力／長さまたは力／面積を持つ。
- 面法線モードでは節点順から得る法線の向きを検証し、要素ごとの法線反転を黙って許さない。
- 平面から許容値を超えて外れた点を XY 等へ投影しない。曲面対応段階までは入力エラーにする。

### 5.5 解析結果と荷重の直接項

入力は `BoundaryCondition.spatial_loads` が保持し、コンパイル結果は解析呼出しごとに生成する。
`Solver` が `SpatialLoadContribution` を保持し、解析結果の `spatial_load_contribution` へスナップショットを
渡す。シェル内部要素ID別の寄与と、載荷パネルID・三角形番号別の節点配分を区別して保持する。
失敗時・再解析時は前回のコンパイル結果を破棄し、入力や構造要素へ累積させない。

支点反力は現行どおり全外力を含む `K u - F` から回収する。直接要素荷重を差し引いた要素節点の
釣合い力を出力する場合は、対応する要素荷重を保持して `K_e*u_e-f_e` を別出力として計算する。
既存シェルの応力・構成則から得る断面合力・辺の力を、この式に置換しない。
載荷三角形から節点荷重を受ける梁には、新たな固定端力補正を追加しない。
節点変位の一致だけで反力・要素出力の一致を推定しない。

次を数値受入契約とする。独立した期待値を第0段階で用意し、第3・第4段階で解析まで検証する。

- パネル節点が拘束節点でも、外力が消えず反力に現れる。
- シェルの要素節点釣合い力を合算した結果が全体反力と整合する。既存の応力由来合力とは区別する。
- パネルから梁へ伝わった荷重が梁端力へ現れる。
- 既存の `pressure` と同じ物理分布を与えた比較モデルで、変位・反力が一致する。

## 8. 実装上の禁止事項

- 節点集合の凸包を、利用者が指定していない載荷領域として黙って採用しない。
- パネル外の点を RBF、最近傍、自然座標の切詰めで黙って外挿しない。
- `interp2d` を別APIへ名前だけ置き換えない。
- 低次求積の誤差を許容誤差の緩和で通さない。
- 解析開始後に入力辞書、メッシュ接続、既存節点荷重を破壊的に変更しない。
- `material_nonlinear` を単位荷重結果の線形重ね合わせで処理しない。
- 変位一致だけで反力・梁端力・シェル結果も正しいと判定しない。
- 前身サンプルの無例外終了や、標準方式と互換方式の相互一致だけを数値正解にしない。
- 既存 `pressure` の符号、面 `F1/F2`、保存形式を今回の都合で変更しない。
- テストの skip、既知失敗追加、保存期待値の一括更新で回帰を隠さない。
