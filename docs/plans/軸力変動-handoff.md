### 対応範囲と次に閉じる条件

1. 同時変動は曲率の同じ正負側で通常骨格・固定枝を追跡する。固定枝のゼロ力／内部復帰／実経験点到達前に接触すれば、その接触を優先できる。直接戻り枝が実経験点以前に骨格へ到達したときは`target`として通常骨格へ進む。
2. 候補Kdの根探索はβ=0、またはそのNd区間で第1・第2曲率点が固定の場合に対応する。後者は任意のβと固定K_minを扱う。非ゼロβでこれらの点が移動する接触状態は`axial_force_path_nonpolynomial_departure`で停止する。一般の非多項式の離脱位置探索を定式化する。
3. 移動再載荷は`axial_force_path_moving_target`、未解決のゼロ力／復帰への到達は`axial_force_path_return_event`、曲率側跨ぎは`axial_force_path_side_crossing`。これらの遷移と一般の目標追越し・同時イベントを独立例から拡張する。Nd一定で実装済みの復帰と同時変動の復帰を混同しない。
4. `AxialForcePathResponse.bending_tangent`は現在枝の曲率偏微分。端点の同時変動写像の整合接線は未実装。イベント位置の感度と`∫C ds`を含む軸・曲げ・せん断の全接線を独立差分で確認する。
5. 本APIが定めるのは直線の`(φ,Nd)`物理経路。非線形軸則のNdを端点間直線で代用して梁へ接続しない。一般化変形経路上で軸則を評価し、軸則イベントを含む局所経路へ拡張する。

## 実装済みの局所契約

`evaluate_bending_plane`は固定JR骨格の一つの曲げ面を評価する純粋関数。`BendingPlaneState`が曲率、せん断一般化変形、M、累積V、JR履歴を保持し、返却された候補を受理する責任は呼出側が持つ。局所評価器自体にcommit／rollbackはない。

確定状態から試行状態への直線経路を実際のJR枝で分割し、各区間の曲げ接線BからCを求める。

```text
I_eff = B / E
C = 12 B GA / (12 B + GA L²)
せん断変形なし: C = 12 B / L²
barC = Σ(C_i × |Δφ_i|) / |φ_t - φ_c|
V_t = V_c + barC × (s_t - s_c)
∂V/∂s = barC
∂V/∂φ = (s_t - s_c) × (C_last - barC) / (φ_t - φ_c)
```

`shear_rigidity`は`GkA`、省略時はせん断変形なし。Mは既存JR評価器の応答を採用する。返却する2×2接線は`[M,V]`を`[φ,s]`で微分したもので、終端枝のB・I・Cとは別物。`Δφ=0`は保存された枝のCを用いる。反転・折れ点で中央差分の一致を要求しない。

区間の探索には履歴コピー上で既存JRのprivateな`_reverse`を使い、最終候補履歴は既存JR評価器から取得する。このアダプターの依存を理解してから接続し、独自の反転則を並立させない。履歴スナップショットの所有を維持し、入力状態を変更しない。

現在の`NonlinearBarElement._section_operators()`は幾何Iから固定Cを計算し、`_evaluate()`は対角の断面接線で組み立てている。ここは未変更。新規モジュールが存在するだけでは解析結果にI更新は反映されない。

- 極端なB/GA比では比がアンダーフローしても有限の`C→GA`を保つ必要がある。現在の安定な係数式を単純な積・商に戻さない。

## 次に行うTDD

### 1. 固定骨格の局所評価器を公開梁へ接続する

最初のRedは公開`NonlinearBarElement`の内力から上記の折れ点跨ぎ参照を検証する試験とする。新しい局所関数だけを直接呼ぶ試験の追加では接続漏れを検出できない。

1. 局所z曲げとy曲げ、せん断変形あり／なし、回転した部材を試験する。符号・対応は現行の一般化変形`[epsilon,tau,kappa_y,kappa_z,s_y,s_z]`を基準とし、`kappa_z↔s_y`、`kappa_y↔s_z`の組を取り違えない。
2. 累積VとJR履歴を同じ確定状態から評価し、両面の2×2接線を6×6の断面接線Dへ組み込む。`f_local=L B_op.T p`、`K_local=L B_op.T D B_op`と座標変換を通した内力・接線を独立差分で確認する。連成項を落とした対角化・対称化をしない。
3. 内力・接線・出力の呼出順を変える試験、commit後の出力、失敗後のrollback、reset、同じ材料を共有する部材間と両軸間の独立性を追加してから状態管理を接続する。既存のJR状態だけでなく、累積V・せん断変形・応答キャッシュも扱う。
4. 公開ソルバーを使い、平坦枝の拘束別継続／停止と全状態rollbackを試験する。局所特異化、負K4、力ゼロ越えも分ける。既存の実ソルバー経路へ接続し、互換ラッパー内に別のソルバーを作らない。
5. 静解析・固有値解析の参照弾性剛性への履歴持越しを防ぎ、再解析と部材分割を確認する。共有`BarParameter`のE・G・幾何Iを書き換えない。

[既存梁断面試験](../../tests/elements/beam/test_nonlinear_section.py)には従来の固定C・対称接線を前提とする期待値がある。折れ点を跨ぐ新接線は非対称になり得る。変更が必要な期待値は手計算・独立式から導き直し、製品出力で参照ファイルを一括上書きしない。

### 2. Nd表と履歴へ進む前に残る定式化を閉じる

レビューで補強した「持続接触・離脱」は文書化のみ。骨格が縮む際に除荷線との交点で原点を更新するだけでは、曲率保持のまま再び骨格外へ出る。計画6.1の接触状態と離脱判定を実装する必要がある。

独立参照は、β=0、Nd=0の点列`(.001,10),(.002,12),(.003,13)`、Nd=1で各Mを半分とする表。Nd=0で`φ=.002`まで載荷し`.0015`へ除荷すると`M=7,Kd=10000`。その曲率を保持してNdを0→1へ進めると`Nd=8/11`で接触し、骨格に追従して`M=5.5`となる。Ndを1→0へ戻すと直ちに離脱し、`M=5.5,Kd=5000`を保持する。負側、境界前後、経路細分化、試行順、rollbackも試験する。

特に未確定の内部復帰経路の再開、移動目標が始点を追い越す場合、負K4延長で複数交点がある場合を先に定式化し、独立期待値を置く。接触はMの符号ではなく骨格の正負側と区間を追跡する。Nd行境界・骨格折れ点・軸方向履歴折れ点・接触／離脱をイベントとして扱い、長さゼロの状態遷移を無限反復させない。

Nd表実装では次の契約を維持する。

- `Nd=-N`、圧縮正。同じ試行状態の中央断面の総軸力を使う。外力、端力の絶対値、前ステップのNdで代用しない。軸方向も非線形なら直線一般化変形経路上で軸則を評価し、Ndを別の直線として補間しない。
- 2行以上、有限・厳密昇順・0を含むNd行。同じ番号の骨格点のPとδを線形補間してから勾配を求める。`K1>=K2>=K3`を各行だけでなく区間全体で検証する。範囲外は診断付きで失敗し、黙ったクランプ・外挿はしない。
- 正負各側のδ4/P4有無は全行で整合させる。既定K_minは全行・正負K1の最小値の1%を固定値として持つ。
- 材料定義は不変・共有、履歴状態は部材／成分ごとに所有する。固定則とNd表を`moment_y`／`moment_z`ごとに選べるようにし、旧入力の互換性を維持する。

### 3. 統合・入出力・受入検証を完了させる

計画の第4～6段階と第10節の全受入項目まで追跡する。表を読み込めるだけ、中央Mだけが変わるだけ、局所試験だけが成功した状態では完了としない。
同じNd行を並べた表が新I更新方式の固定則に帰着すること、軸方向を含む全接線、釣合い、入力全経路、再読込み、刻み感度、診断とrollback、公開利用例を確認する。
現行`run()`は毎回状態をresetするため、2回の呼出しを鉛直先行載荷後の独立水平継続載荷として扱わない。荷重ステージ機能は別課題である。
