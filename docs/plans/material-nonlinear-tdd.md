# 材料非線形解析の修正プラン（TDD）

作成日: 2026-09-08 / 調査時の HEAD: d6fb6df

## 目的と進め方

材料非線形解析レビューで見つかった問題を、物理的な不変条件と手計算に基づくテストで修正する。
各段階で Red（修正前に失敗）→ Green（修正後に成功）→ 整理・回帰確認を行う。
実装自身から生成した数値を期待値にしない。既存サンプルの期待結果を自動上書きしない。
修正と検証の実績は `docs/report/material-nonlinear-tdd.md` に記録する。

## 第2段階: 梁要素の内力・接線剛性（完了、下記の定式化・検証範囲）

### 採用する定式化（2026-09-08、実装前の決定）

7.21節の中央断面モデルを採用する。小変位・小回転、右手系の局所座標で
`q=(ux,uy,uz,rx,ry,rz)_i,j`、`ε=(ux_j-ux_i)/L`、
`κy=(ry_j-ry_i)/L`、`κz=(rz_j-rz_i)/L`、`τ=(rx_j-rx_i)/L` とする。
`ry` は4・10、`rz` は5・11。正の軸ひずみは引張、正の曲率・ねじり率はj端回転の増加。

| 適用先 | 入力δ | 入力P | dP/dδの単位（力F・長さℓ） |
|---|---|---|---|
| axial | 軸ひずみε（無次元） | 軸力N（F） | F（弾性時EA） |
| moment_y / moment_z | 中央曲率κ（rad/ℓ） | 中央断面モーメントM（Fℓ） | Fℓ²（弾性時EI） |
| torsion | ねじり率τ（rad/ℓ） | ねじりモーメント（Fℓ） | Fℓ²（弾性時GJ） |

`s_y=(uy_j-uy_i)/L-(rz_i+rz_j)/2`、
`s_z=(uz_j-uz_i)/L+(ry_i+ry_j)/2` を用い、
`C_y=1/[1/(G κ_y A)+L²/(12EI_z)]`、
`C_z=1/[1/(G κ_z A)+L²/(12EI_y)]` とする（せん断変形なしでは第一項を0）。
ここでκ_y,κ_zは断面のせん断補正係数であり曲率とは別。
一般化変形 `e=Bq=(ε,τ,κy,κz,s_y,s_z)`、一般化力
`p=(N,T,My,Mz,C_y s_y,C_z s_z)` から `f_local=L Bᵀp`、
`K_local=L Bᵀ diag(dp/de) B` を同時に導く。未指定成分はEA,GJ,EIの線形則。
`f_global=Tᵀ f_local`、`K_global=Tᵀ K_local T`。
弾性せん断成分のCは基準のE,I,G,Aから固定する。履歴接線によってIやCを更新する
7.21節の手順そのものは採用しない（その依存性を無視すると整合接線にならないため）。
曲げ非線形は中央一断面に限定し、分布塑性・集中ヒンジ・軸力曲げ相互作用は表現しない。

入力調査: `file_io.py` はδ,Pを無変換で読み、`beam001.json` はmoment_zに
δ=(1e-5,1e-4,1e-3), P=(1000,3000,5000)を指定するが、単位・ヒンジ長のメタデータはない。
`material.py` とwikiの「変位m・荷重N」という一律説明は7.21節の曲率と矛盾する。
JSON/Pythonのキーと値は維持し、上表の意味で解釈する。過去の誤った絶対端部変位での計算値は維持しない。
旧入力の物理単位・較正は利用者による再確認が必要。既存サンプルは変更しない。
M―相対回転θの骨格は、明示したヒンジ長ℓpがある場合に限りκ=θ/ℓpへ換算可能だが、
本要素は集中ヒンジを実装せず、自動換算もしない。複数適用先は同じ数値の骨格を使う現行APIを維持し、
異なる単位の骨格を自動生成しない。必要なら要素APIで適用先ごとに設定する。

状態は適用先ごとの中央一点で持つ。内力の各試行は確定状態のコピーから評価し、
接線・出力は試行候補も進めない。commitでのみ確定、rollbackで候補と内力を復元する。
収束時の変位と内力を保存し、その断面力出力にJR則の再評価を使わない。
JR内部の反転・ゼロ通過・ループ・K_minの修正は第3段階に残す。

## 第3段階: 履歴状態とJR履歴則（完了、下記の補完仕様・検証範囲）

### 実装前の照合・採用仕様（2026-09-08）

`current_delta/P`は評価の出発点となる直近の確定値、`previous_delta/P`は
その一つ前の診断用の値。増分・方向・反転点はcurrentから求める。
保持（δがcurrentと同値）は力・接線・履歴をそのまま返し、updateでも進めない。
試行評価はコピー上で全イベントを追跡し、返した候補をupdateがコピーする。
要素のcommit/rollbackと中央断面の定式化は第2段階を維持する。

| 枝・イベント | 式・遷移と現行との差 |
|---|---|
| 未ひび割れ | 正負それぞれの原点直線。両側が未ひび割れなら反転しても弾性 |
| 骨格 | 各側の(0,0),(δ1,P1),(δ2,P2),(δ3,P3)を結ぶ。負側入力は絶対値 |
| 反転 | currentの(δr,Pr)で直ちに開始。除荷枝はP=Pr+Kd(δ−δr) |
| 力ゼロ | δ0=δr−Pr/Kd。δの符号ではなく、移動方向でδ0への到達を判定 |
| 再載荷 | P=Pt(δ−δ0)/(δt−δ0)。目標は変位符号でなく移動方向で選ぶ |
| 外部目標 | 出発側最大がδ2以下なら反対側のmax(経験最大,δ1)、δ2超ならmax(経験最大,δ2) |
| 内部反転 | 再載荷枝の反転点と中断した枝をスタックに保存。次の逆向き再載荷は一つ前の反転点へ |
| 戻り点 | 入れ子の反転点を対で除去し、中断枝を再開。同じ試行で残りの移動も追跡 |
| ゼロ前の再反転 | 同じ除荷直線を戻り、除荷開始点で元の枝を再開（7.11に詳細のない補完仕様） |

戻り剛性は出発する力の側の最大経験変形を用いる。内部でその側をまだ経験していない
場合はその側の初期剛性を使う。内部反転のδそのもので外部最大を置き換えず、剛性回復を防ぐ。
`delta_max_pos/neg`は骨格外も含む全経験変形の最大絶対値、`P_max_pos/neg`は
その点の力の絶対値（全履歴の最大力とは限らない）。外部目標は最大変形と骨格の交点、
内部目標は記録した実際の反転点とする。枝のKdと目標は反転時に固定し、途中で更新しない。
非対称則の側の選択、未到達の仮想目標、ゼロ前の再反転、入れ子の復帰は
7.11に完全な定義がないため、本段階の明示的な補完仕様として検証する。

戻り剛性は、d=出発側最大の絶対値として次を採用する。

- d≤δ1: Kd=K1。
- δ1<d≤δ2: Kd=min(K1,max(K_min,K2,K1(d/δ1)^(-β)))。
- δ2<d: Kd=min(K1,max(K_min,K2(d/δ2)^(-β)))。

7.11.1の下限は第2区間のK2に等しい。これを7.11.2・3へ拡張しない。
理論の厳密不等号は極限を含む閉区間クリップで扱う（β=0等の端点を許容）。
δ2ちょうどでは「超えた場合」という記述に合わせ第2区間式を使う。
この式の領域切替によりKd自体はδ2で不連続になり得る。
K_minは戻り剛性だけに適用し、骨格や再載荷の接線には適用しない。

仕様が入力から決まらない第4勾配は**K4=0（終局耐力一定）**とする。
現行のK3×0.01と数値EPSILONによる人工勾配には理論・入力の根拠がないため除く。
耐力低下・破断・任意のK4入力は今回の範囲外。
7.11.2・3ではδ0が名目目標を追い越すことがある。この場合、正の再載荷接線で
名目目標へ進めないため、除荷直線と移動先骨格の最初の前方交点まで目標を拡張する。
ゼロから交点までは同じKd、その交点で骨格に移る。定数耐力の第4枝とKd>0により
有限の交点が存在する。内部目標でも前方接続不能なら同じ補完を適用し、交点で内部履歴を
消去して骨格へ復帰する。これは連続性を保つための補完で、原文から一意に導ける仕様ではない。

入力はすべて有限、0<δ1<δ2<δ3、0<P1≤P2≤P3、
K1≥K2≥K3≥0、β≥0、0<K_min≤min(K1正,K1負)に限定する。
初期勾配を上回る硬化等は剛性低減RC型の範囲外として拒否する。
K_min省略値は正負初期剛性の小さい方の1%。対称時は従来と同じ。
材料APIも同じ検証を使い、E>0、−1<ν<0.5、任意密度≥0を有限値で検証する。
折れ点では骨格は絶対変形が増える側、履歴遷移は進行方向の次の枝の片側接線を返す。
保持時は直前に採用した接線を維持する。各直線の錨点を固定し、刻み細分化に依存させない。
