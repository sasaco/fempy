# 材料非線形解析の修正プラン（TDD）

作成日: 2026-09-08 / 調査時の HEAD: d6fb6df

## 目的と進め方

材料非線形解析レビューで見つかった問題を、物理的な不変条件と手計算に基づくテストで修正する。
各段階で Red（修正前に失敗）→ Green（修正後に成功）→ 整理・回帰確認を行う。
実装自身から生成した数値を期待値にしない。既存サンプルの期待結果を自動上書きしない。
修正と検証の実績は `docs/report/material-nonlinear-tdd.md` に記録する。

## 第1段階: 境界条件と非線形ソルバーの土台（今回の修正単位）

- [x] 4節点中の節点4だけを固定しても正しい6自由度に拘束が入ることを再現する。
- [x] 3自由度のソリッドと6自由度の梁の区別を呼び出し元から明示する。
- [x] 強制変位を正確に消去法で扱い、自由DOFへの右辺補正と行列の対称性を検証する。
- [x] 非線形反復では強制変位の「目標値−現在値」を使う。荷重係数に応じて目標値を増加させる。
- [x] 支持ばねの力を残差にも含め、ばねDOFを固定DOFとして収束判定から除外しない。
- [x] 非線形Newton方程式で、特異行列を人工的な剛性追加により成功扱いしない。
- [x] 未収束・線形方程式失敗時は変位と要素履歴を最後の確定状態へ戻し、後続荷重へ進めず、例外で未完了を通知する。
- [x] 収束時の内力から支持反力を出す。線形要素だけの非線形経路を手計算と比較する。
- [x] `FemModel()` の解析パラメータを初期化し、無効な反復パラメータを開始前に拒否する。
- [x] 回帰確認で判明した飛び番節点を、昇順の連続DOFへ写像する。剛性・質量・荷重・境界条件・変位・反力・後処理の変位抽出を統一する。
- [x] 固定節点への巨大荷重で自由DOFの残差を過小評価しないことを検証する。

ここでは荷重刻みの自動縮小を実装せず、失敗したら停止する。失敗を結果と誤認しないことを優先する。
材料則を分離してソルバーを検証するため、線形梁・独立した一自由度モデルもテストに用いる。
第1段階の実装・専用テストは完了。全体テストに残る既存の非線形サンプル失敗はレポート参照。

## 第2段階: 梁要素の内力・接線剛性

- [ ] 軸方向の剛体並進で内力ゼロ、端部力の釣合いを Red にする。
- [ ] 内力の有限差分と接線剛性の一致を、線形域・非線形域・回転した部材で確認する。
- [ ] `moment_y` / `moment_z` の軸対応を修正する。
- [ ] repoの理論マニュアル7.21節を基に曲げの定式化・符号・単位を確定する。
  曲げのモーメント―曲率、集中ヒンジのモーメント―相対回転角を混同しない。
- [ ] 弾性極限、剛体回転、純曲げ、せん断との釣合い、要素分割の影響を確認する。
- [ ] 出力断面力を非線形の収束内力と一致させる。
  基底クラスの `calculate_stress_strain()` が `NotImplementedError` を投げるため、
  `hasattr` だけの後処理では線形梁の `calculate_forces()` にも到達しない点を併せて修正する。

## 第3段階: 履歴状態とJR履歴則

- [ ] 同じ確定状態・試行変形から同じ結果が得られることを検証する。
- [ ] 試行評価は確定履歴を変更せず、収束したときだけcommitする。
- [ ] 反転を直近の確定変形から検出し、反復途中の行き過ぎを実載荷として記憶しない。
- [ ] 力ゼロ通過、ゼロ力点から目標点への連続性、非対称骨格、K_minを検証する。
- [ ] 内部ループと戻り点の復帰を7.11節と照合し、履歴刻みの細分化による整合性を確認する。
- [ ] 材料パラメータの有限性・単位・順序と、第4勾配の仕様を明文化する。

## 第4段階: 入出力・統合検証

- [ ] HTTP入口の解析タイプ選択と、未収束のエラー出力を検証する。
- [ ] 非線形サンプルの収束、固定端、全体釣合い、独立した参照値を検証する。
- [ ] テストの期待値自動生成を除き、数値比較が実際に呼ばれるようにする。
- [ ] 外部実装または独立した手計算との照合を行う。単なるサンプル完走を正しさの証明としない。

## 完了条件

第1段階完了と、材料非線形解析全体の妥当性確認は区別する。
全体の完了には第2〜4段階の受け入れ条件も必要であり、未実施事項はレポートに残す。
