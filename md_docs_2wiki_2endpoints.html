POST / - 構造解析

提供されたモデルデータに対して構造解析を実行します。

リクエスト

ヘッダー

  • Content-Type: application/json
  • Content-Encoding: gzip (オプション、圧縮リクエスト用)

リクエストボディ

リクエストボディには構造モデルを表すJSONオブジェクトを含める必要があります。データはgzipエンコーディングを使用してオプションで圧縮できます。

基本構造:

{
"node": { ... },
"member": { ... },
"element": { ... },
"fix_node": { ... },
"load": { ... }
}

圧縮サポート: APIは大きなモデルに対してgzip圧縮をサポートします。圧縮データを送信する場合：

  1. JSON文字列をgzipで圧縮
  2. 圧縮データをbase64でエンコード
  3. Content-Encoding: gzip ヘッダーを設定

レスポンス

成功レスポンス (200 OK)

すべての荷重ケースの解析結果を返します。

{
"loadCase1": {
"disg": { ... },
"reac": { ... },
"fsec": { ... },
"shell_fsec": { ... },
"shell_results": { ... },
"size": 100
},
"loadCase2": { ... }
}

レスポンス圧縮

大きなレスポンスは以下の場合に自動的にgzipで圧縮され、base64エンコードされます：

  • レスポンスサイズが内部閾値を超える場合
  • クライアントが圧縮をサポートする場合

圧縮レスポンスには以下が含まれます：

  • Content-Encoding: gzip ヘッダー
  • Base64エンコードされたgzip圧縮JSONデータ

エラーレスポンス

400 Bad Request

無効な入力データ形式または必須フィールドの欠如。

{
"error": "入力データエラー",
"message": "節点データが不足しています",
"details": {
"node": 5,
"member": 3
}
}

500 Internal Server Error

解析計算エラーまたはシステム障害。

{
"error": "計算エラー",
"message": "剛性行列の特異性により解析が収束しませんでした",
"details": {
"loadCase": "case1",
"caseComb": {
"nMaterialCase": 1,
"nSupportCase": 1,
"nSpringCase": 1,
"nJointCase": 1
}
}
}

GET / - ヘルスチェック

基本的なサービス情報とヘルス状態を返します。

リクエスト

リクエストボディは不要です。

レスポンス

{
"service": "FrameWeb3",
"status": "running",
"version": "3.0",
"timestamp": "2025-05-31T12:35:04Z"
}
