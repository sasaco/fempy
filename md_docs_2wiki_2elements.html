要素と解析の選び方

Wikiホーム · モデルの入力 · 実行例

部材を線で表すなら梁、厚さに比べて広い面ならシェル、厚みを含む内部の状態を調べるならソリッドを使います。要素を選んだ後、線形静解析・材料非線形解析・固有値解析を選びます。

解析モード

analysis_type 計算内容 選ぶ場面
static 参照弾性剛性を使い、全荷重を1ステップで解く 弾性範囲の変形・応力を調べる
material_nonlinear 載荷段階ごとに材料の履歴と釣合いを反復計算 剛性低下、除荷・再載荷、残留変形を調べる
modal 剛性行列と質量行列から固有値問題を解く 振動数・周期・振動モードを調べる

model.run("static")のような明示指定が最優先です。引数を省略すると入力のanalysis_typeを使い、それもない場合はnonlinear_barがあればmaterial_nonlinear、なければstaticになります。n_load_stepsを増やすだけでは非線形解析になりません。

非線形梁を含むモデルにstaticを指定すると、履歴則を使わない参照弾性解析になります。弾性剛性は材料のE・Gと断面から計算するため、入力した非線形骨格の初期勾配と一致するように設定したかを確認してください。

状態と全aliasを含む機械可読な定義はPythonからも取得できます。

from fem import get_capability_registry
capabilities = get_capability_registry()

質量行列があることは、あらゆる支持条件・形状で固有値計算が成功するという意味ではありません。密度、不要自由度、収束を確認する必要があります。

pyramidとhexa20はクラス名・入口が残っていますが、必要な計算が未実装です。20節点六面体を使う場合の実装済み名称は**hexa2**です。旧名称TetraElement2、WedgeElement2、HexaElement2はそれぞれ二次要素に対応します。

梁：曲げとせん断変形

梁は1節点につき並進3成分・回転3成分を持ちます。局所x軸はi端からj端、曲げの剛性はE Iy・E Iz、ねじりの剛性はG Jです。

  • shear_correction: false：せん断変形を無視するBernoulli系の梁。
  • shear_correction: true：基準弾性のせん断柔性を含むTimoshenko系の梁。

**node/member/element形式のJSONでは、材料のGを省略すると、梁のshear_correctionは必ずfalseになります。** 線形・非線形梁の両方に適用されます。ねじりに使うGは引き続きE/[2(1+nu)]から計算します。

JSON材料のG 部材のshear_correction 実際の設定
省略 省略・false・trueのいずれでも false
有限かつ正の値 false false
有限かつ正の値 true true
有限かつ正の値 省略 選択材料ケースに非線形材料があればtrue、線形材料だけならfalse

この省略規則はPython APIや保存用materials/elements形式には適用されません。そちらでは明示したshear_correctionを保持します。剛域に別材料を割り当てた場合は、その区間の材料に対して規則を適用します。

材端解放・分布ばね・分布荷重・温度荷重は、対応する線形梁の経路で利用します。nonlinear_barにこれらを直接組み合わせる入力は対応していません。非線形梁の載荷には節点荷重・強制変位を使い、必要に応じて線形梁と接続してください。

シェル：薄板と厚板

現行のシェルは平面要素です。傾いた平面は扱いますが、1要素の節点を曲面上にねじって配置する使い方ではありません。

形状と入口 既定の曲げ定式化 特徴
編集用JSONの三角形shell、旧TriElement1 dkt 離散Kirchhoff曲げ。薄板向けで横せん断変形を無視
Python／保存用JSONの三角形shell mindlin 横せん断変形を含む。薄板ではせん断ロッキングに注意
四角形shell mindlin Mindlin曲げとMITC4せん断補間

三角形はformulation: "dkt"または"mindlin"で明示できます。四角形にdktは指定できません。厚さは編集用JSONでは材料のthicknessまたはA、Python・保存用JSONでは要素のthicknessで指定します。

応力の上下面・座標系・せん断ひずみの定義は結果の読み方を参照してください。DKTの合せん断力は曲げモーメントの釣合いから回復したもので、横せん断変形を導入した結果ではありません。

ソリッド：一次と二次

ソリッドは1節点につき並進3成分です。梁用のA, Iy, Iz, Jは使わず、座標から形状・体積を求めます。材料は小ひずみの等方線形弾性です。

二次要素には辺の中間節点が必要です。頂点だけを渡したり、中間節点を省略したりすることはできません。下表の辺番号は、入力配列内の**1始まりの位置**です。

要素 最初に置く頂点 続ける中間節点の辺順序
tetra2 四面体の頂点1〜4 1–2、2–3、3–1、1–4、2–4、3–4
wedge2 底面の三角形1〜3、対応する上面4〜6 1–2、2–3、3–1、4–5、5–6、6–4、1–4、2–5、3–6
hexa2 底面を一周する1〜4、対応する上面5〜8 1–2、2–3、3–4、4–1、5–6、6–7、7–8、8–5、1–5、2–6、3–7、4–8

正のヤコビアンになる向きで頂点を並べます。二次四面体の実行例に具体的な座標を示します。詳細な自然座標は要素定義で確認できます。

固有値解析の設定と制約

model.analysis_params["n_modes"] = 3のように指定してmodel.run("modal")を呼ぶか、model.run_modal_analysis(n_modes=3)を使います。要求数は正の整数で、利用可能な自由度数を超える場合はエラーになります。要求数を無言で減らしません。

  • 密度はPython／保存用JSONではdensity、編集用JSONではdenです。N・m・s系ではkg/m³、kN・m・s系ではt/m³になります。要素ごとの密度の既定値に頼らず指定してください。
  • 梁の質量行列は集中質量の近似です。連続体の厳密解との比較では、要素分割と質量の表現による差を確認してください。
  • 拘束自由度は剛性・質量行列の両方から同じ配置で除き、固有ベクトルを全自由度へ復元します。支持ばねは剛性へ加えます。
  • 質量を持たない自由度が残るモデルは、誤って削除せずエラーにします。不要自由度を拘束するか、要素の慣性定義を確認してください。
  • ARPACKの未収束時は低次選択を保つシフト反転を一度試し、再び失敗すれば要求数を減らさずエラーにします。
  • 行列尺度に対して丸め誤差と判断できる負値だけを0とし、有意な負固有値は不安定性としてエラーにします。
  • ゼロモードの周期はPython結果ではinf、HTTP・保存JSONではnullです。正のモードの周期と区別してください。
  • eigenpair_residualsとmass_orthogonality_errorで数値検査値を確認できます。これらは実構造との妥当性確認の代わりではありません。
  • 非線形解析後の接線剛性による振動解析ではありません。履歴状態を引き継いだ固有値解析として利用しないでください。

固有値解析の実行例は、明示した密度と支持条件を使います。

対応範囲を広げるとき

要素を細かくした結果を比較し、変位だけでなく反力と応力・端力の変化も確認してください。自動分割は指定位置や荷重位置で区切る処理であり、誤差を推定して自動的に収束メッシュを作る機能ではありません。

異なる要素を接続したモデルでは、共有節点の自由度と力の伝達を確認します。特にソリッドだけの節点には回転剛性がないため、梁・シェルとの混在時に不要な回転自由度を残さないようにします。
